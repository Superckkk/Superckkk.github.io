朴素匹配在失配时把主串指针往回退，而 KMP 的核心观察是：**模式串自己最了解自己**——失配位置之前的那段模式串，其最长相等前后缀告诉我们，下一次比较可以从哪里安全地开始。

## next 数组

`next[j]` 的定义：模式串前 `j` 个字符中，最长相等前后缀的长度。计算它是动态规划的自我引用：

```c
next[1] = 0;
for (int i = 2, j = 0; i <= m; i++) {
    while (j > 0 && p[i] != p[j+1]) j = next[j];
    if (p[i] == p[j+1]) j++;
    next[i] = j;
}
```

## 修正值 nextval

当 `p[j] == p[next[j]]` 时，滑动到 `next[j]` 仍必然失配，可以继续向前回溯——这就是 2024 统考真题里"修正后的 next 数组"的由来。
