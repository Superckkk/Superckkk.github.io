<!-- stem -->
假设循环单链表表示的队列长度为$n$,队头固定在链表尾,若只设头指针,则入队操作的时间复杂度为:

<!-- answer -->
**【错误解法】** $O(1)$

**【正确解法】** $O(n)$

头指针指链表头指针.入队要在队尾插入新结点,就要找到队尾的前驱结点.而队尾的位置为链表表头,无法访问其前驱,需要遍历链表.

<!-- q {"id": "ds-ch03-q2", "type": "练习", "tags": ["栈、队列和数组"], "title": "2014统考真题：循环队列判空判满"} -->

<!-- stem -->
(2014统考真题)循环队列放在一维数组`A[0...M-1]`中,`end1`指向队首元素,`end2`指向队尾元素的后一个位置.假设队列两端均可进行入队和出队操作,队列中最多能容纳M-1个元素,初始时为空.下列判断队空和队满的条件中,正确的是:

<!-- answer -->
**【错误解法】**

- 队空:`end2 == (end1+1) mod M;`
- 队满:`end1 == (end2+1) mod M;`

**【正确解法】**

- 队空:`end1 == end2;`
- 队满:`end1 == (end2+1) mod M;`

`end1`指向队首元素,说明出队操作时,应当执行:`x = A[end1];end1 = (end1+1) mod M;`;`end2`指向队尾元素的后一个位置,说明入队操作时,应当执行:`A[end2] = x;end2 = (end2+1) mod M;`.

初始时为空,入队时的第一个元素应当位于`A[0]`处,因此初始时`end2`应当为0.第一个元素出队时,应当从`A[0]`处出队,因此初始时`end1`应当为0.因此队空条件为`end1 == end2;`

同理分析可得队满条件为`end1 == (end2+1) mod M;`
