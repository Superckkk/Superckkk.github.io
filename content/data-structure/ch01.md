<!-- q {"id": "ds-ch01-q3", "type": "练习", "tags": ["绪论"], "title": "双重循环的时间复杂度"} -->

<!-- stem -->
下列程序段的时间复杂度是＿＿＿.

```c
int sum = 0;
for(int i = 1;i < n; i *= 2){
  for(int j = 1;j <= i; j++){
    count++;
  }
}
```

<!-- answer -->
$i$的变化：$1, 2, \cdots, \sqrt{n}$

$j$的变化：$1, 2, \cdots i$

因此`count++`这条指令需要执行$1+2+\cdots+\sqrt{n} = \frac{1}{2}\left(\sqrt{n} + n\right)$次,因此时间复杂度为$O(n)$

<!-- q {"id": "ds-ch01-q4", "type": "练习", "tags": ["绪论"], "title": "递归函数的时间复杂度"} -->

<!-- stem -->
下列函数代码的时间复杂度是＿＿＿.

```c
int Func(int n){
  if(n == 1) return 1;
  else return 2*Func(n/2) + n;
}
```

<!-- answer -->
1. 设`Func(n)`的运行时间为$T(n)$,则:

$$T(n) = T(n/2) + c = T(n/4) + 2c = \cdots = T(1) + c \log n$$

因此$T(n) = O(\log n)$

2. 使用主定理，$T(n) = T(n/2) + c, \ a = 1, b = 2, f(n) = c$,符合情况2，$f(n) = \Theta\left(n^{\log_b a}\right) = \Theta(1),$则

$$T(n) = \Theta\left(n^{\log_b a} \log n\right) = \Theta(\log n)$$
