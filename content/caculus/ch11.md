<!-- q {"id": "calc-ch11-q1", "type": "练习", "tags": ["积分等式与不等式"], "title": "推广的积分中值定理及其应用"} -->

<!-- stem -->
(1)设$f(x), g(x)$在$[a,b]$上连续,且$g(x)$在$[a,b]$上不变号,证明:存在$\xi \in (a,b)$,使得

$$\int_a^b f(x) g(x)\,\mathrm{d}x = f(\xi) \int_a^b g(x)\, \mathrm{d}x$$

(2)设$f(x)$在$[1,2]$上连续,计算$\lim\limits_{n\to\infty} \int_1^2 f(x) e^{-x^n}\, \mathrm{d}x$

<!-- answer -->
(1).

- 若$g(x) = 0$,则结论显然成立
- 若$g(x) \neq 0$,则不妨假设$g(x) > 0$.令$F(x) = \int_a^x f(t) g(t)\,\mathrm{d}t, \ G(x) = \int_a^x g(t)\,\mathrm{d}t$,则在$[a,b]$上对其使用柯西中值定理,可得:

$$\begin{aligned}
\frac{F(b) - F(a)}{G(b) - G(a)} &= \frac{F'(\xi)}{G'(\xi)} \quad (\xi \in (a,b))\\
\Longrightarrow \frac{\int_a^b f(x) g(x)\,\mathrm{d}x}{\int_a^b g(x)\,\mathrm{d}x} &= \frac{f(\xi) g(\xi)}{g(\xi)}\\
\Longrightarrow \int_a^b f(x) g(x)\,\mathrm{d}x &= f(\xi) \int_a^b g(x)\,\mathrm{d}x
\end{aligned}$$

(2).

① 由(1)可知:$\int_1^2 f(x) e^{-x^n}\, \mathrm{d}x = f(\xi_n) \int_1^2 e^{-x^n}\, \mathrm{d}x, \ 1 < \xi_n < 2$.因为$f(x)$在$[1,2]$上连续,故$f(\xi_n)$有界.又$x \in (1,2), \ e^{x^n} > x^n + 1 > 0$,故$\dfrac{1}{e^{x^n}} < \dfrac{1}{x^n + 1} < \dfrac{1}{x^n}$.因此:

$$\begin{aligned}
&0 < \int_1^2 e^{-x^n}\, \mathrm{d}x < \int_1^2 x^{-n}\, \mathrm{d}x = \frac{1}{1-n} \left(2^{1-n} - 1\right)\\
&\lim_{n\to\infty} \frac{1}{1-n} \left(2^{1-n} - 1\right) = 0
\end{aligned}$$

由夹逼准则知$\lim\limits_{n\to\infty} \int_1^2 e^{-x^n}\, \mathrm{d}x = 0$,故$\lim\limits_{n\to\infty} \int_1^2 f(x) e^{-x^n}\, \mathrm{d}x = 0$（有界$\times$无穷小量）

考虑这样一种解法:

② 由(1)可知:$\int_1^2 f(x) e^{-x^n}\, \mathrm{d}x = e^{- \xi^n} \int_1^2 f(x)\, \mathrm{d}x, \ 1 < \xi_n < 2$,因此:

$$\lim_{n\to\infty} \int_1^2 f(x) e^{-x^n}\, \mathrm{d}x = \lim_{n\to\infty} e^{- \xi^n} \int_1^2 f(x)\, \mathrm{d}x = \int_1^2 f(x)\, \mathrm{d}x \lim_{n\to\infty} e^{- \xi^n} = 0$$

第二种解法存在问题,你能看出来吗?

问题出在:

- <mark>由(1)可知:$\int_1^2 f(x) e^{-x^n}\, \mathrm{d}x = e^{- \xi^n} \int_1^2 f(x)\, \mathrm{d}x, \ 1 < \xi_n < 2$</mark>,然而,(1)中的结论并不能推导出这个等式,因为推导时要求$g(x)$在$[a,b]$上不变号,而第(2)问中并没有给出$f(x)$在$[1,2]$上不变号的条件,故不能使用
- <mark>$\lim\limits_{n\to\infty} e^{-\xi^n} = 0$</mark>. 对于$\int_1^2 e^{-x^n}\, \mathrm{d}x,$若写成$\int_1^2 e^{-x^n}\, \mathrm{d}x = e^{- \xi_n^n}$,$\xi_n$与$n$有关,且其趋向性不确定,极限值未知,因此不能直接推出$\lim\limits_{n\to\infty} e^{-\xi_n^n} = 0$

<!-- q {"id": "calc-ch11-q2", "type": "练习", "tags": ["积分等式与不等式"], "title": "∫(n+1)xⁿln(1+x)dx 的极限"} -->

<!-- stem -->
$\lim\limits_{n\to\infty} \int_0^1 (n+1) x^n \ln(1+x)\, \mathrm{d}x = ＿＿＿.$

<!-- answer -->
$$\begin{aligned}
\int_0^1 (n+1) x^n \ln(1+x)\, \mathrm{d}x &= \int_0^1 \ln(1+x)\, \mathrm{d}\left(x^{n+1}\right)\\
&= \left. x^{n+1} \ln(1+x) \right|^1_0 - \int_0^1 \frac{x^{n+1}}{1+x}\, \mathrm{d}x\\
&= \ln 2 - \int_0^1 \frac{x^{n+1}}{1+x}\, \mathrm{d}x
\end{aligned}$$

$$\int_0^1 \frac{x^{n+1}}{2}\, \mathrm{d}x < \int_0^1 \frac{x^{n+1}}{1+x}\, \mathrm{d}x < \int_0^1 x^n\, \mathrm{d}x$$

$$\begin{aligned}
\lim_{n\to\infty} \int_0^1 \frac{x^{n+1}}{2}\, \mathrm{d}x &= \lim_{n\to\infty} \left. \frac{1}{2(n+2)} x^{n+2} \right|^1_0 = 0\\
\lim_{n\to\infty} \int_0^1 x^n\, \mathrm{d}x &= \lim_{n\to\infty} \left. \frac{1}{n+1} x^{n+1} \right|^1_0 = 0
\end{aligned}$$

因此$\lim\limits_{n\to\infty} \left(\ln 2 - \int_0^1 \dfrac{x^{n+1}}{1+x}\, \mathrm{d}x\right) = \ln 2 + \lim\limits_{n\to\infty} \int_0^1 \dfrac{x^{n+1}}{1+x}\, \mathrm{d}x = \ln 2$

而如果我们用上面一题的结论会如何呢?

$$\lim_{n\to\infty} \int_0^1 (n+1) x^n \ln(1+x)\, \mathrm{d}x = \lim_{n\to\infty} \ln\left(1+\xi_n\right) \int_0^1 (n+1) x^n\, \mathrm{d}x = \lim_{n\to\infty} \ln\left(1+\xi_n\right)$$

下面需要做的是求解$\lim\limits_{n\to\infty} \ln\left(1+\xi_n\right)$.将积分区间$[0,1]$拆分为$[0, \delta], [\delta, 1]$,则:

$$\lim_{n\to\infty} \int_0^{\delta} (n+1) x^n \ln(1+x)\, \mathrm{d}x = \ln\left(1+\xi_{1,n}\right) \lim_{n\to\infty} \left. x^{n+1} \right|^{\delta}_0 = 0$$

$$\lim_{n\to\infty} \int_{\delta}^1 (n+1) x^n \ln(1+x)\, \mathrm{d}x = \lim_{n\to\infty} \left(\ln\left(1+\xi_n\right) - \int_0^{\delta} (n+1) x^n \ln(1+x)\, \mathrm{d}x\right) = \lim_{n\to\infty} \ln\left(1+\xi_n\right)$$

又因为$[\delta, 1]$上,$\ln(1+x) \in \left[\ln(1+\delta), \ln 2\right],$因此

$$\begin{aligned}
\ln(1+\delta) \lim_{n\to\infty} \int_{\delta}^1 (n+1) x^n\, \mathrm{d}x &\le \lim_{n\to\infty} \ln\left(1+\xi_n\right) \le \ln 2 \lim_{n\to\infty} \int_{\delta}^1 (n+1) x^n\, \mathrm{d}x\\
\ln(1+\delta) &\le \lim_{n\to\infty} \inf \ln\left(1+\xi_n\right) < \lim_{n\to\infty} \sup \ln\left(1+\xi_n\right) \le \ln 2
\end{aligned}$$

由$\delta$的任意性,令$\delta \to 1^-$,则$\lim\limits_{n\to\infty} \ln\left(1+\xi_n\right) = \ln 2$

**【推论】** 设$f(x)$在$[0,1]$上连续,则

- $\lim\limits_{n\to\infty} \int_0^1 x^n f(x)\, \mathrm{d}x = 0$
- $\lim\limits_{n\to\infty} \int_0^1 (n+1) x^n f(x)\, \mathrm{d}x = f(1)$

<!-- q {"id": "calc-ch11-q4", "type": "练习", "tags": ["积分等式与不等式"], "title": "f 单调增加、0≤g≤1 的积分不等式"} -->

<!-- stem -->
设函数$f(x), g(x)$在区间$[a,b]$上连续,且$f(x)$单调增加,$0 \le g(x) \le 1$.证明:

(1) $0 \le \displaystyle\int_a^x g(t)\, \mathrm{d}t \le x - a, \ x \in [a,b]$

(2) $\displaystyle\int_a^{a+\int_a^b g(t)\, \mathrm{d}t} f(x)\, \mathrm{d}x \le \int_a^b f(x) g(x)\, \mathrm{d}x$

<!-- answer -->
(1). 略

(2). 令$F(x) = \displaystyle\int_a^{a+\int_a^x g(u)\, \mathrm{d}u} f(t)\, \mathrm{d}t - \int_a^x f(t) g(t)\, \mathrm{d}t$

因为$f(x), g(x)$均在$[a,b]$上连续,所以$F(x)$在$[a,b]$上可导,有

$$F'(x) = f\left[a+\int_a^x g(u)\, \mathrm{d}u\right] g(x) - f(x) g(x) = \left\{f\left[a+\int_a^x g(u)\, \mathrm{d}u\right] - f(x)\right\} g(x)$$

由(1)可知:$a + \displaystyle\int_a^x g(u)\, \mathrm{d}u \le a + x - a = x$,又因为$f(x)$单调增加,故$f\left[a+\int_a^x g(u)\, \mathrm{d}u\right] - f(x) \le 0$,又因为$g(x) \ge 0$,故$F'(x) \le 0$. $F(a) = 0$,故$F(b) \le 0$,即:

$$\int_a^{a+\int_a^b g(u)\, \mathrm{d}u} f(x)\, \mathrm{d}x \le \int_a^b f(x) g(x)\, \mathrm{d}x$$

复杂的$F(x)$让人头疼,那是否存在简洁优美的办法呢?有的兄弟,有的:

**【提示】（重排不等式）** 假设存在实数$a_1 > a_2 > \cdots > a_n, \ b_1 > b_2 > \cdots > b_n, \ \sigma_1, \sigma_2, \cdots, \sigma_n$是$b_1, b_2, \cdots, b_n$的任意重排,则有:

$$a_1 b_1 + a_2 b_2 + \cdots + a_n b_n \ge a_1 \sigma_1 + a_2 \sigma_2 + \cdots + a_n \sigma_n \ge a_1 b_n + a_2 b_{n-1} + \cdots + a_n b_1$$

一言以蔽之:若有两数列,则其对应项乘积之和在顺序排列时达到最大,逆序排列时达到最小.

那么我们如何利用重排不等式解决该题呢?我们已经知道:积分其实就是另一种视角下的求和,我们令$S = \displaystyle\int_a^b g(x)\, \mathrm{d}x, \ 0 < S < b-a$,那么$\displaystyle\int_a^b f(x) g(x)\, \mathrm{d}x$就对应于上面的$a_1 \sigma_1 + a_2 \sigma_2 + \cdots + a_n \sigma_n$.

$f(x)$单调增加,根据重排不等式,我们将$g(x)$排列成单调不增的形式,则$\displaystyle\int_a^b f(x) g(x)\, \mathrm{d}x$就可以达到最小值.考虑极端情况,将$g(x)$集中在$f(x)$较小部分,因为$S = \displaystyle\int_a^b g(x)\, \mathrm{d}x$,则可以令:

$$g(x) = \begin{cases} 1 & x \in [a, a+S]\\ 0 & x \in [a+S, b] \end{cases}$$

此时

$$\min \int_a^b f(x) g(x)\, \mathrm{d}x = \int_a^{a+S} f(x)\, \mathrm{d}x = \int_a^{a+\int_a^b g(t)\, \mathrm{d}t} f(x)\, \mathrm{d}x$$

因此

$$\int_a^{a+\int_a^b g(t)\, \mathrm{d}t} f(x)\, \mathrm{d}x \le \int_a^b f(x) g(x)\, \mathrm{d}x$$

**【注意】**

虽然此方法很巧妙,但是步骤相比标准方法(构造$F(x)$)不够严谨,若在考场上有时间和思路,还是建议使用标准方法,若是填空题或选择题可以使用此方法

<!-- answer -->
拆分积分区间$[0,1]$为$[0,x], [x,1]$,则:

- $f(x) - f(0) = f'(\xi_1)x, \ \left|f(x)\right| = \left|f'(\xi_1)\right| x \le M x$
- $f(x) - f(1) = (x-1)f'(\xi_2), \ \left|f(x)\right| = \left|f'(\xi_2)\right| (1-x) \le M (1-x)$

因此:

$$\begin{aligned}
\left|\int_0^1 f(x)\, \mathrm{d}x\right| &= \left|\int_0^x f(t)\, \mathrm{d}t + \int_x^1 f(t)\, \mathrm{d}t\right|\\
&\le \left|\int_0^x f(t)\, \mathrm{d}t\right| + \left|\int_x^1 f(t)\, \mathrm{d}t\right|\\
&\le M \left|\int_0^x t\, \mathrm{d}t\right| + M \left|\int_x^1 (1-t)\, \mathrm{d}t\right|\\
&= M\left(\frac{1}{2} x^2 + \frac{1}{2} (1-x)^2\right)\\
&= M \left[\left(x-\frac{1}{2}\right)^2 + \frac{1}{4}\right] \le \frac{1}{4} M
\end{aligned}$$

- (B) $I_1 < 0, I_2 > 0$
- (C) $I_1 < 0, I_2 < 0$
- (D) $I_1 > 0, I_2 > 0$

<!-- answer -->
$$\begin{aligned}
I_1 = \int_{-\pi}^{\pi} f(x) \sin x\, \mathrm{d}x &= \int_{-\pi}^0 f(x) \sin x\, \mathrm{d}x + \int_0^{\pi} f(x) \sin x\, \mathrm{d}x\\

\end{aligned}$$

由于$f'(x) > 0$,故在$(0, \pi)$上,有$f(x) > f(-x),$因此$I_1 > 0$

**【错误解法】**

$$\begin{aligned}
I_2 = \int_{-\pi}^{\pi} f(x) \cos x\, \mathrm{d}x &= \int_{-\pi}^0 f(x) \cos x\, \mathrm{d}x + \int_0^{\pi} f(x) \cos x\, \mathrm{d}x\\
&= - \int_{\pi}^0 f(-t) \cos t\, \mathrm{d}t + \int_0^{\pi} f(x) \cos x\, \mathrm{d}x\\
&= \int_0^{\pi} \left(f(x) + f(-x)\right) \cos x\, \mathrm{d}x
\end{aligned}$$

推导过程没错,但是也只能止步于此了,我们不知道$f(x)$哪怕某一个点的具体值,因此无法判断$f(x) + f(-x)$的正负.(如果知道$f(0)$就可以,利用了凸函数的性质)
