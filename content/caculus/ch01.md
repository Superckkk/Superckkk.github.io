<!-- q {"id": "calc-ch01-q1", "type": "练习", "tags": ["函数与极限"], "title": "泰勒公式反求参数"} -->

<!-- stem -->
已知极限 $\lim\limits_{x\to 0} \dfrac{\tan(2x) + x f(x)}{\sin(x^3)} = 0$，且 $f(0)=0$，求 $\lim\limits_{x\to 0} \dfrac{2 + f(x)}{x^2}$。

<!-- answer -->
**方法一：脱帽法（定义法）**

$\lim\limits_{x\to 0} \dfrac{\tan(2x) + x f(x)}{\sin(x^3)} = 0$,则$\dfrac{\tan(2x) + x f(x)}{x^3} = \alpha(x)$,其中$\alpha(x)$为$x\to 0$时的无穷小.因此

$$\begin{aligned}
f(x) &= \frac{x^3 \cdot \alpha(x) - \tan(2x)}{x}\\
\lim_{x\to 0} \frac{2+f(x)}{x^2} &= \lim_{x\to 0} \frac{2 + \frac{x^3 \cdot \alpha(x) - \tan(2x)}{x}}{x^2}\\
&= \lim_{x\to 0} \frac{2x - \tan(2x) + x^3 \alpha(x)}{x^3}\\
&= \lim_{x\to 0} \frac{2x - \left[2x + \frac{1}{3}(2x)^3 + o(x^3)\right] + x^3 \alpha(x)}{x^3} = - \frac{8}{3}
\end{aligned}$$

**方法二：泰勒公式（推荐）**

由 $\sin(x^3) \sim x^3$，原极限存在意味着分子也是 $o(x^3)$。

展开 $\tan(2x) = (2x) + \frac{1}{3}(2x)^3 + o(x^3) = 2x + \frac{8}{3} x^3 + o(x^3)$。

代入分子：

$$2x + \frac{8}{3} x^3 + o(x^3) + x f(x) = o(x^3)$$

两边同除以 $x$ (当 $x\neq 0$)：

$$2 + \frac{8}{3} x^2 + o(x^2) + f(x) = o(x^2)$$

整理得：

$$2 + f(x) = -\frac{8}{3} x^2 + o(x^2)$$

故所求极限为：

$$\lim_{x\to 0} \frac{2+f(x)}{x^2} = -\frac{8}{3}$$

<!-- q {"id": "calc-ch01-q2", "type": "练习", "tags": ["函数与极限"], "title": "φ(x) 相关结论正误判定"} -->

<!-- stem -->
已知$\lim\limits_{x\to x_0} \phi(x) = 0$,则下列结论正确的个数是＿＿＿.

- (A) $\lim\limits_{x\to x_0} \dfrac{\sin \phi(x)}{\phi(x)} = 1$
- (B) $\lim\limits_{x\to x_0} \left[1+\phi(x)\right]^{\frac{1}{\phi(x)}} = e$
- (C) 当$x \to x_0$时,$\sin \phi(x) \sim \phi(x)$
- (D) 若$\lim\limits_{u\to 0} f(u) = A$,则$\lim\limits_{x\to x_0} f\left[\phi(x)\right] = A$

<!-- answer -->
正确的结论个数为0.

**【注意】** $\lim\limits_{x\to x_0} f(x) = A.$指的是:$\forall \epsilon > 0, \exists \delta > 0, \text{s.t.}$ 当 <mark>$0 < \left|x - x_0\right| < \delta$</mark>,有 $\left|f(x) - A\right| < \epsilon.$注意:两个都是<mark>$<$</mark>而非$\le$,也就是在$x \to x_0$的过程中,$x$是不会取到$x_0$的.不论$f(x_0)$实际是什么值,函数极限只与函数在$x_0$的<mark>去心邻域</mark>内的行为有关

- (A):我们知道的是：$\lim\limits_{x\to 0} \dfrac{\sin x}{x} = 1$,$x$虽然在分母的位置,但是由于极限考虑的是$0$的去心邻域,所以$x$实际上不会取到$0$.而当我们将$x$替换成$\phi(x)$时,$\phi(x)$在0的去心邻域内是可以取到0的，这将导致整个分式无意义.所以(A)是错误的
- (B):重要极限:$\lim\limits_{x\to 0} (1+x)^{1/x} = e$,和(A)一样注意分母的问题,所以(B)也是错误的
- (C):(A)的错误自然会导致(C)的错误
- (D):$\lim\limits_{u\to 0} f(u) = A \not\Longrightarrow f(0) = A.$考虑极端情况,$\phi(x) = 0$为常函数,那么$\lim\limits_{x\to x_0} f\left[\phi(x)\right] = f(0)$不一定为$A$,故(D)错误

因此四个结论全部错误
