<!-- q {"id": "calc-ch19-q1", "type": "练习", "tags": ["附录"], "title": "三个积分比大小与“帮手”理论"} -->

<!-- stem -->
设$I_1 = \displaystyle\int_0^{\pi/2} \frac{\cos x}{1+x^2}\, \mathrm{d}x, \quad I_2 = \int_0^{\pi/2} \frac{\sin x}{1+x^2}\, \mathrm{d}x, \quad I_3 = \int_0^{\pi/2} \frac{\sin x}{(1+x)^2}\, \mathrm{d}x$,则（ ）

- (A) $I_1 > I_2 > I_3$
- (B) $I_3 > I_2 > I_1$
- (C) $I_2 > I_1 > I_3$
- (D) $I_3 > I_1 > I_2$

<!-- answer -->
当$x \in \left[0, \dfrac{\pi}{2}\right]$时,$(1+x)^2 = 1 + x^2 + 2x \ge 1+x^2$,故:

$$I_2 = \int_0^{\pi/2} \frac{\sin x}{1+x^2}\, \mathrm{d}x \ge \int_0^{\pi/2} \frac{\sin x}{(1+x)^2}\, \mathrm{d}x = I_3$$

下面比较$I_1$和$I_2$的大小,作差:

$$I_1 - I_2 = \int_0^{\pi/2} \frac{\cos x - \sin x}{1+x^2}\, \mathrm{d}x = \int_0^{\pi/4} \frac{\cos x - \sin x}{1+x^2}\, \mathrm{d}x + \int_{\pi/4}^{\pi/2} \frac{\cos x - \sin x}{1+x^2}\, \mathrm{d}x$$

对积分区间为$\left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$的部分,作换元$t = \dfrac{\pi}{2} - x$,得:

$$\int_{\pi/4}^{\pi/2} \frac{\cos x - \sin x}{1+x^2}\, \mathrm{d}x \overset{x = \frac{\pi}{2} - t}{=} \int_0^{\pi/4} \frac{\sin t - \cos t}{1 + \left(\frac{\pi}{2} - t\right)^2}\, \mathrm{d}t$$

因此:

$$\begin{aligned}
I_1 - I_2 &= \int_0^{\pi/4} (\cos x - \sin x)\left[\frac{1}{1+x^2} - \frac{1}{1+ \left(\frac{\pi}{2} -x\right)^2}\right] \mathrm{d}x\\
&= \int_0^{\pi/4} (\cos x - \sin x) \frac{\left(\frac{\pi}{2} - x\right)^2 - x^2}{\left(1+x^2\right)\left[1 + \left(\frac{\pi}{2} - x\right)^2\right]} \mathrm{d}x
\end{aligned}$$

$x \in \left[0, \dfrac{\pi}{4}\right]$时,$\cos x > \sin x, \ 0 < x < \dfrac{\pi}{2} - x$,因此$I_1 - I_2 > 0, \ I_1 > I_2$

综上:$I_1 > I_2 > I_3$

**【笔记】** 以上是严谨的代数推导.针对于选择题,博主给出的"帮手"理论,具体操作为:若要比较$I_1, I_2$的大小,先作差:

$$I_1 - I_2 = \int_0^{\pi/2} \left(\cos x - \sin x\right) \frac{1}{1+x^2}\, \mathrm{d}x$$

作出函数图像,可以看到:$f(x) = \cos x - \sin x$是一个关于点$\left(\dfrac{\pi}{4}, 0\right)$中心对称的函数,而$\dfrac{\pi}{4}$恰好是积分区间的中点.而函数$g(x) = \dfrac{1}{1+x^2}$是在积分区间$\left[0, \dfrac{\pi}{2}\right]$上递减的函数,我们将其称作$f(x)$的帮手.

那么从图像上可见:$g(x)$不断递减,则其作为"帮手"的作用,在$f(x)$的正区间,即$\left[0, \dfrac{\pi}{4}\right)$上更大,而对负区间上的帮助更小,因此$\displaystyle\int_0^{\pi/2} f(x) g(x)\, \mathrm{d}x > 0 \Rightarrow I_1 > I_2$

**【推论（"帮手"引理）】**

设$f$在区间$[a,b]$上关于区间中点$m = \dfrac{a+b}{2}$中心反对称,即:$f(m+u) + f(m-u) = 0$,且$f(x) \ge 0, \ x \in [a, m]$.设$g$在$[a,b]$上单调不增,则:

$$\int_a^b f(x) g(x)\, \mathrm{d}x \ge 0$$

关于$f(x) \le 0, \ x \in [a, m]$的情况,根据对称性易得,不等号取反即可.

<!-- q {"id": "calc-ch19-q2", "type": "练习", "tags": ["附录"], "title": "区间再现：∫₀^π x sin x/(1+cos²x) dx"} -->

<!-- stem -->
$$I = \int_0^{\pi} \frac{x \sin x}{1+\cos^2 x}\, \mathrm{d}x$$

<!-- answer -->
**【背景】（区间再现）** $I = \displaystyle\int_a^b f(x)\, \mathrm{d}x = \int_a^b f(a+b-x)\, \mathrm{d}x \Rightarrow I = \dfrac{1}{2} \displaystyle\int_a^b \left[f(x) + f(a+b - x)\right] \mathrm{d}x$。该方法常用于积分项出现三角函数的情形，因为三角函数本身具有周期性与对称性，有 $\sin x = \sin(\pi-x), \ \sin x = \cos\left(\dfrac{\pi}{2} - x\right)$。

$$\begin{aligned}
I &= \frac{1}{2} \int_0^{\pi} \left[\frac{x \sin x}{1+\cos^2 x} + \frac{(\pi-x) \sin(\pi-x)}{1 + \cos^2 (\pi-x)} \right] \mathrm{d}x\\
&= \frac{1}{2} \int_0^{\pi} \left[\frac{x \sin x}{1+\cos^2 x} + \frac{(\pi-x) \sin x}{1 + \cos^2 x}\right] \mathrm{d}x\\
&= \frac{\pi}{2} \int_0^{\pi} \frac{\sin x}{1+\cos^2 x}\, \mathrm{d}x = \frac{\pi^2}{4}
\end{aligned}$$

**【笔记】** 又比如经典的欧拉对数积分:

$$\begin{aligned}
I = \int_0^{\pi/2} \ln(\sin x)\, \mathrm{d}x &= \frac{1}{2} \int_0^{\pi/2} \left[\ln(\sin x) + \ln(\cos x)\right] \mathrm{d}x\\
&= \frac{1}{2} \left(\int_0^{\pi/2} \ln(\sin 2x)\, \mathrm{d}x - \frac{\pi}{2} \ln 2\right)\\
&= \frac{1}{2} \left(\frac{1}{2} \int_0^{\pi} \ln(\sin u)\, \mathrm{d}u - \frac{\pi}{2} \ln 2\right)\\
&= \frac{1}{2} \left(I - \frac{\pi}{2} \ln 2\right)\\
&= -\frac{\pi}{2} \ln 2
\end{aligned}$$

<!-- q {"id": "calc-ch19-q3", "type": "练习", "tags": ["附录"], "title": "构造对称区间：∫₀² x(x−1)²⁰²³ dx"} -->

<!-- stem -->
$$I = \int_0^{2} x \left(x-1\right)^{2023} \mathrm{d}x$$

<!-- answer -->
**【背景】（构造对称区间）** 对于任意定积分 $\displaystyle\int_a^b f(x)\, \mathrm{d}x$，做平移变换 $t = x - \dfrac{a+b}{2}$，则积分区间变为关于原点对称的 $[-L, L]$（$L = \dfrac{b-a}{2}$），此时 $\displaystyle\int_a^b f(x)\, \mathrm{d}x = \int_{-L}^{L} f\left(t+\dfrac{a+b}{2}\right) \mathrm{d}t$。若 $g(t)$ 是奇函数，则积分为 0，若为偶函数，则为 $2\displaystyle\int_0^L g(t)\, \mathrm{d}t$。

做换元$ t = x - 1$,则有:

$$\begin{aligned}
I &= \int_{-1}^{1} (t+1)\, t^{2023}\, \mathrm{d}t\\
&= \int_{-1}^{1} \left(t^{2024} + t^{2023}\right) \mathrm{d}t\\
&= 2 \int_0^1 t^{2024}\, \mathrm{d}t\\
&= \frac{2}{2025}
\end{aligned}$$

<!-- q {"id": "calc-ch19-q4", "type": "练习", "tags": ["附录"], "title": "构造对称区间：∫₀^π cos(x+cos x) dx"} -->

<!-- stem -->
$$I = \int_0^{\pi} \cos\left(x + \cos x\right) \mathrm{d}x$$

<!-- answer -->
做换元$t = x - \dfrac{\pi}{2}$,则有:

$$\begin{aligned}
I &= \int_{-\pi/2}^{\pi/2} \cos\left(t + \frac{\pi}{2} - \sin t\right) \mathrm{d}t\\
&= \int_{-\pi/2}^{\pi/2} \sin\left(\sin t - t\right) \mathrm{d}t = 0
\end{aligned}$$

**【笔记】** "区间再现"中的这一题也可以利用"构造对称区间"解决:

$$I = \int_0^{\pi} \frac{x \sin x}{1 + \cos^2 x}\, \mathrm{d}x$$

$$\begin{aligned}
\text{Let } t = x - \frac{\pi}{2}, \quad \text{Then } I &= \int_{-\pi/2}^{\pi/2} \frac{\left(t+\frac{\pi}{2}\right) \cos t}{1 + \sin^2 t}\, \mathrm{d}t\\
&= \underbrace{\int_{-\pi/2}^{\pi/2} \frac{t \cos t}{1+\sin^2 t}\, \mathrm{d}t}_{\text{odd function}} + \underbrace{\frac{\pi}{2} \int_{-\pi/2}^{\pi/2} \frac{\cos t}{1+\sin^2 t}\, \mathrm{d}t}_{\text{even function}}\\
&= \pi \int_0^{\pi/2} \frac{\cos t}{1+\sin^2 t}\, \mathrm{d}t\\
&= \frac{\pi^2}{4}
\end{aligned}$$

**【说明】** 最后一题用两种方法得到相同的结果,且计算量也差不多,不禁让人思考:这两个方法有没有内在的联系?实际上,通过推导可以发现:

- 区间再现:

$$I = \frac{1}{2} \int_a^b \left[f(x) + f(a+b-x)\right] \mathrm{d}x$$

- 构造对称区间:

$$I = \int_0^L \left[g(t) + g(-t)\right] \mathrm{d}t, \quad \text{Where } t = x - \frac{a+b}{2}, \ L = \frac{b-a}{2}$$

对构造对称区间得到的式子进一步操作:

$$\begin{aligned}
I &= \int_0^L \left[g(t) + g(-t)\right] \mathrm{d}t\\
&= \int_m^b \left[g(x-m)+ g(m-x)\right] \mathrm{d}x \quad \text{Where } m = \frac{a+b}{2}\\
&= \int_m^b \left[f(x) + f(a+b-x)\right] \mathrm{d}x \quad \text{Since } g(x) = f(x+m)
\end{aligned}$$

而$\left[f(x) + f(a+b-x)\right]$这个式子本身关于$[a,b]$的区间中点$m$是对称的,因此:

$$\int_m^b \left[f(x) + f(a+b-x)\right] \mathrm{d}x = \frac{1}{2} \int_a^b \left[f(x) + f(a+b-x)\right] \mathrm{d}x$$

因此,经过几步变换,"区间再现"和"构造对称区间"两种方法得到了完全相同的式子.
