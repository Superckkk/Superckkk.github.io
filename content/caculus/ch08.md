<!-- stem -->
函数$f(x) = \begin{cases} \dfrac{1}{\sqrt{1+x^2}} & x \le 0\\ (x+1)\cos x & x > 0 \end{cases}$的一个原函数为（ ）

- (A) $F(x) = \begin{cases} \ln\left(\sqrt{1+x^2} - x\right) & x \le 0\\ (x+1)\cos x - \sin x & x > 0 \end{cases}$
- (B) $F(x) = \begin{cases} \ln\left(\sqrt{1+x^2} - x\right) + 1 & x \le 0\\ (x+1)\cos x - \sin x & x > 0 \end{cases}$
- (C) $F(x) = \begin{cases} \ln\left(\sqrt{1+x^2} + x\right) & x \le 0\\ (x+1)\sin x + \cos x & x > 0 \end{cases}$
- (D) $F(x) = \begin{cases} \ln\left(\sqrt{1+x^2} + x\right) + 1 & x \le 0\\ (x+1)\sin x + \cos x & x > 0 \end{cases}$

<!-- answer -->
$F'(x) = f(x)$.<mark>由$f(x)$处处有定义得$F(x)$处处可导</mark>,推出$F(x)$处处连续,因此答案为$(D)$

<!-- stem -->
在区间$[-1,2]$上，以下四个结论哪些是正确的：

① $f(x) = \begin{cases} 2 & x > 0\\ 1 & x = 0\\ -1 & x < 0 \end{cases}$,有原函数，但其定积分不存在；

② $f(x) = \begin{cases} 2 x \sin\dfrac{1}{x^2} - \dfrac{2}{x} \cos\dfrac{1}{x^2} & x \neq 0\\ 0 & x = 0 \end{cases}$,有原函数，其定积分也存在；

③ $f(x) = \begin{cases} \dfrac{1}{x} & x \neq 0\\ 0 & x = 0 \end{cases}$,没有原函数，但其定积分也不存在；

④ $f(x) = \begin{cases} 2x \cos\dfrac{1}{x} + \sin\dfrac{1}{x} & x \neq 0\\ 0 & x = 0 \end{cases}$,有原函数，其定积分也存在。

<!-- answer -->
- 对于①：由前面的学习我们可以知道的是：可导函数不会导出非连续的函数（将振荡间断视为特殊的连续）,因此该函数不存在原函数，①错误
- 对于②：易知函数$F(x) = x^2 \sin\dfrac{1}{x^2}$是$f(x)$的一个原函数,而对于$f(x)$,由于$\lim\limits_{x\to 0} F(x)$是无穷振荡,因此其在$[-1,2]$上无界,因此不存在定积分，②错误
- 对于③：$f(x)$在区间内包含无穷间断点,故其既没有原函数,定积分也不存在,③正确
- 对于④：易知函数$F(x) = x^2 \cos\dfrac{1}{x}$是$f(x)$的一个原函数,且在$[-1,2]$上有界且只有一个振荡间断点,因此其定积分存在，④正确

综上,正确的结论为③,④

<!-- q {"id": "calc-ch08-q3", "type": "练习", "tags": ["积分"], "title": "M = ∫sin(sin x) 与 N = ∫cos(cos x)"} -->

<!-- stem -->
设$M = \int_0^{\pi/2} \sin(\sin x)\,\mathrm{d}x, \quad N = \int_0^{\pi/2} \cos(\cos x)\,\mathrm{d}x$,则（ ）

- (A) $M < 1 < N$
- (B) $M < N < 1$
- (C) $N < M < 1$
- (D) $1 < M < N$

<!-- answer -->
在$\left[0, \frac{\pi}{2}\right]$上,由于$\sin x$单调递增,$\sin x < x$,因此$\sin(\sin x) < \sin x$,$\int_0^{\pi/2} \sin(\sin x)\,\mathrm{d}x < \int_0^{\pi/2} \sin x\,\mathrm{d}x = 1$,故$M < 1$.

在$\left[0, \frac{\pi}{2}\right]$上,由于$\cos x$单调递减,$\cos x < \frac{\pi}{2} - x$,因此$\cos(\cos x) > \cos\left(\frac{\pi}{2} - x\right)$,$\int_0^{\pi/2} \cos(\cos x)\,\mathrm{d}x > \int_0^{\pi/2} \cos\left(\frac{\pi}{2} - x\right) \mathrm{d}x = 1$,故$N > 1$.

因此答案为$(A)$.

由此题可得一个结论:<mark>$\int_0^{\pi/2} f(\sin x)\,\mathrm{d}x = \int_0^{\pi/2} f(\cos x)\,\mathrm{d}x$</mark>

<!-- q {"id": "calc-ch08-q4", "type": "练习", "tags": ["积分"], "title": "可去间断点对变限积分可导性的影响"} -->

<!-- stem -->
设$f(x) = \begin{cases} e^{x^2} + x^2 & x \neq 0\\ a & x = 0 \end{cases}$其中$a$为常数,令$F(x) = \int_{-1}^x f(t)\,\mathrm{d}t$,则以下命题:

① 当$a = 1$时,$F(x)$在$x = 0$处可导;

② 当$a \neq 1$时,$F(x)$在$x = 0$处可导;

③ 当$a = 1$时,$F(x)$在$x = 0$处不可导;

④ 当$a \neq 1$时,$F(x)$在$x = 0$处不可导;

所有真命题的序号为（ ）

- (A) ①,④
- (B) ①,②
- (C) ③,④
- (D) ②,③

<!-- answer -->
易知:$\lim\limits_{x\to 0} f(x) = 1$,$x = 0$是连续点或可去间断点,因此该点并不会影响$F(x)$在该点的可导性,故$a = 1$或$a \neq 1$,$F(x)$在$x = 0$处都可导,因此真命题的序号为①②,答案为$(B)$

<!-- q {"id": "calc-ch08-q5", "type": "练习", "tags": ["积分"], "title": "∫1/(xᵃ+xᵇ) 收敛的条件"} -->

<!-- stem -->
设$a > b > 0$,反常积分$\displaystyle\int_0^{+\infty} \frac{1}{x^a + x^b}\,\mathrm{d}x$收敛,则（ ）

- (A) $a > 1$ 且 $b > 1$
- (B) $a > 1$ 且 $b < 1$
- (C) $a < 1$ 且 $a+b > 1$
- (D) $a < 1$ 且 $b < 1$

<!-- answer -->
仔细观察就会发现,前面的重要结论中的四个结论均无法直接套用：结论一要求积分区间为$[0,1]$,结论二要求积分区间为$[a, +\infty]$,其中$a > 0$.因此我们需要拆分题目中的积分区间。

$$\int_0^{+\infty} \frac{1}{x^a + x^b}\,\mathrm{d}x = \int_0^1 \frac{1}{x^a + x^b}\,\mathrm{d}x + \int_1^{+\infty} \frac{1}{x^a + x^b}\,\mathrm{d}x = I_1 + I_2$$

- 对于$I_1$:由于$x = 0$是瑕点,因此我们考虑这点的情况：$\lim\limits_{x\to 0^+} \dfrac{x^a + x^b}{x^b} = 1$,因此该积分的敛散性与$\int_0^1 \dfrac{1}{x^b}\,\mathrm{d}x$的收敛性相同,由重要结论可知,该积分收敛当且仅当$b < 1$.
- 对于$I_2$:则需要考虑$x \to +\infty$的情况,同理可知该积分收敛当且仅当$a > 1$.

因此,当$a > 1$ 且 $b < 1$时,该积分收敛.答案为$(B)$

<!-- stem -->
若反常积分$\displaystyle\int_1^{+\infty} \left(e^{-\cos \frac{1}{x}} - e^{-1}\right) x^k\, \mathrm{d}x$收敛,则$k$的取值范围是＿＿＿

<!-- q {"id": "calc-ch08-q7", "type": "练习", "tags": ["积分"], "title": "四个反常积分中发散的是"} -->

<!-- stem -->
以下反常积分发散的是（ ）

- (A) $\displaystyle\int_1^{+\infty} \left[\ln\left(1+\frac{1}{x}\right)-\frac{1}{1+x}\right] \mathrm{d}x$
- (B) $\displaystyle\int_0^{+\infty} \frac{\ln x}{1+x^2}\, \mathrm{d}x$
- (C) $\displaystyle\int_{-1}^{1} \frac{\mathrm{d}x}{\sin x}$
- (D) $\displaystyle\int_{-\infty}^{+\infty} \frac{\sin x}{1+x^2}\, \mathrm{d}x$

<!-- answer -->
- 对于A:当$x \in (1, +\infty), \ln\left(1+\frac{1}{x}\right) < \frac{1}{x}, \ln\left(1+\frac{1}{x}\right) - \frac{1}{1+x} < \frac{1}{x} - \frac{1}{1+x} < \frac{1}{x^2}$.而由于$\int_1^{+\infty} \dfrac{1}{x^2}\,\mathrm{d}x$收敛,因此原积分收敛
- 对于B:首先应对积分区间进行拆分:$\int_0^{+\infty} \dfrac{\ln x}{1+x^2}\, \mathrm{d}x = \int_0^1 \dfrac{\ln x}{1+x^2}\, \mathrm{d}x + \int_1^{+\infty} \dfrac{\ln x}{1+x^2}\, \mathrm{d}x = I_1 + I_2$.
  - 对于$I_1$:瑕点为$x = 0, \lim\limits_{x\to 0^+} \dfrac{\frac{\ln x}{1+x^2}}{1/x^{1/2}} = \lim\limits_{x\to 0^+} \sqrt{x} \ln x = 0,$因此$I_1$的敛散性与$\int_0^1 \ln x\,\mathrm{d}x$相同.又因为$\lim\limits_{x\to 0^+} \dfrac{\ln x}{1/\sqrt{x}} = \lim\limits_{x\to 0^+} \sqrt{x} \ln x = 0$, 而 $\int_0^1 \dfrac{1}{\sqrt{x}}\,\mathrm{d}x$收敛,故$\int_0^1 \ln x\,\mathrm{d}x$收敛,故$I_1$收敛.

    **【注意】** 容易想到的是$\lim\limits_{x\to 0^+} \dfrac{\frac{\ln x}{1+x^2}}{x^2} = 0$,但是$\int_0^1 \dfrac{1}{x^2}\,\mathrm{d}x$发散,因此不能直接用此极限来判断$I_1$的敛散性
  - 对于$I_2$:$\dfrac{\ln x}{1+x^2} < \dfrac{\ln x}{x^2}$, 而 $\int_1^{+\infty} \dfrac{\ln x}{x^2}\, \mathrm{d}x$收敛(可通过分部积分计算得到),因此$I_2$也收敛
  - 因此原积分B收敛
- 对于C:同样应先对积分区间进行拆分:$\int_{-1}^1 \dfrac{1}{\sin x}\, \mathrm{d}x = \int_{-1}^0 \dfrac{1}{\sin x}\, \mathrm{d}x + \int_0^1 \dfrac{1}{\sin x}\, \mathrm{d}x = I_1 + I_2$.而对于$x \in (0,1), \dfrac{1}{\sin x} > \dfrac{1}{x}$,而$\int_0^1 \dfrac{1}{x}\,\mathrm{d}x$发散,故$I_1$发散,故原积分发散
- 对于D:被积函数是一个奇函数,因此在$x = 0$处拆分.$\int_{-\infty}^{+\infty} \dfrac{\sin x}{1+x^2}\, \mathrm{d}x = \int_{-\infty}^0 \dfrac{\sin x}{1+x^2}\, \mathrm{d}x + \int_0^{+\infty} \dfrac{\sin x}{1+x^2}\, \mathrm{d}x = I_1 + I_2$. $I_1 < \int_0^{+\infty} \dfrac{1}{1+x^2}\, \mathrm{d}x = \arctan x \Big|^{+\infty}_0 = \dfrac{\pi}{2}$,因此原积分收敛

<!-- q {"id": "calc-ch08-q8", "type": "练习", "tags": ["积分"], "title": "对数和的极限（积分和）"} -->

<!-- stem -->
$\lim\limits_{n\to\infty} \dfrac{1}{n^3} \left[\ln \dfrac{1}{n} + 4\ln \dfrac{2}{n} + \cdots + (n-1)^2 \ln \dfrac{n-1}{n}\right] = ＿＿＿$

<!-- answer -->
原式可写为 $\lim\limits_{n \to +\infty} \dfrac{1}{n} \sum\limits_{k=1}^{n-1} \left(\dfrac{k}{n}\right)^2 \ln \dfrac{k}{n}$，这是区间 $[0,1]$ 上的积分和。

因此原式 $= \int_0^1 x^2 \ln x\,\mathrm{d}x$。

利用分部积分：设 $u = \ln x$，$\mathrm{d}v = x^2\, \mathrm{d}x$，则 $\mathrm{d}u = \dfrac{1}{x}\, \mathrm{d}x$，$v = \dfrac{x^3}{3}$。

$$\int_0^1 x^2 \ln x\,\mathrm{d}x = \left[\frac{x^3}{3} \ln x\right]_0^1 - \int_0^1 \frac{x^3}{3} \cdot \frac{1}{x}\, \mathrm{d}x = 0 - \frac{1}{3} \int_0^1 x^2\, \mathrm{d}x = -\frac{1}{3} \cdot \frac{1}{3} = -\frac{1}{9}$$

答案为 $-\dfrac{1}{9}$。

**【注意】** 注意计算出积分的最终结果，不要只写出积分表达式。

<!-- q {"id": "calc-ch08-q9", "type": "练习", "tags": ["积分"], "title": "M、N、K 三个积分比较大小"} -->

<!-- stem -->
设 $M = \displaystyle\int_{-1/2}^{1/2} \left(1 + \dfrac{x}{1+x^2}\right) \mathrm{d}x$，$N = \displaystyle\int_0^1 \dfrac{(1+x) \ln^2 (1+x)}{x^2}\, \mathrm{d}x$，$K = \displaystyle\int_0^1 \dfrac{e^x}{1+x}\, \mathrm{d}x$，则（ ）

- (A) M < N < K
- (B) M < K < N
- (C) N < M < K
- (D) N < K < M

<!-- answer -->
**计算 M：**

由于 $\dfrac{x}{1+x^2}$ 是奇函数，在对称区间上积分为 0，故

$$M = \int_{-1/2}^{1/2} 1\,\mathrm{d}x = 1$$

**估计 N：**

令$g(x) = (1+x) \ln^2 (1+x) - x^2$,求导两次可得$g(x) < 0$,故$N < 1$

**估计 K：**

$K = \displaystyle\int_0^1 \dfrac{e^x}{1+x}\, \mathrm{d}x$，由于 $e^x > 1 + x$，故 $\dfrac{e^x}{1+x} > 1$，因此 $K > 1$。

综上，$N < M = 1 < K$，即 $N < M < K$。

答案为 **(C)**。

<!-- q {"id": "calc-ch08-q10", "type": "练习", "tags": ["积分"], "title": "分段函数定积分的最小区间"} -->

<!-- stem -->
设 $f(x) = \begin{cases} x \ln x & x > 0\\ x^2 + x & x \le 0 \end{cases}$，若 $\displaystyle\int_a^b f(x)\,\mathrm{d}x$ 取得最小值，则 $(a, b) = $（ ）

- (A) $(-1,1)$
- (B) $(-1,2)$
- (C) $(0,1)$
- (D) $(1,2)$

<!-- answer -->
要使 $F(a, b) = \displaystyle\int_a^b f(x)\,\mathrm{d}x$ 最小，需要尽量多地包含 $f(x) < 0$ 的区域，避免 $f(x) > 0$ 的区域。

**分析 $f(x)$ 的符号：**

- 当 $x > 0$ 时：$f(x) = x \ln x$，在 $(0,1)$ 上 $\ln x < 0$，故 $f(x) < 0$；在 $(1,+\infty)$ 上 $f(x) > 0$。
- 当 $x \le 0$ 时：$f(x) = x^2 + x = x(x+1)$，在 $(-1,0)$ 上 $f(x) < 0$；在 $(-\infty,-1)$ 上 $f(x) > 0$。

因此 $f(x) < 0$ 的区域为 $(-1, 0) \cup (0, 1) = (-1, 1) \setminus \{0\}$。

要使积分最小，应取 $a = -1$，$b = 1$。

答案为 **(A)**。

<!-- q {"id": "calc-ch08-q11", "type": "练习", "tags": ["积分"], "title": "反函数积分的取值范围"} -->

<!-- stem -->
若 $\sqrt{1-x^2}$ 是 $x f(x)$ 的一个原函数，则 $\displaystyle\int_0^1 \dfrac{1}{f(x)}\,\mathrm{d}x = $（ ）

- (A) $-1$
- (B) $\dfrac{\pi}{4}$
- (C) $-\dfrac{\pi}{4}$
- (D) $1$

<!-- answer -->
由题意，$\left(\sqrt{1-x^2}\right)' = x f(x)$。

计算导数：

$$\left(\sqrt{1-x^2}\right)' = \frac{-2x}{2\sqrt{1-x^2}} = -\frac{x}{\sqrt{1-x^2}}$$

因此 $x f(x) = -\dfrac{x}{\sqrt{1-x^2}}$，即 $f(x) = -\dfrac{1}{\sqrt{1-x^2}}$（$x \neq 0$）。

故 $\dfrac{1}{f(x)} = -\sqrt{1-x^2}$。

$$\int_0^1 \dfrac{1}{f(x)}\,\mathrm{d}x = -\int_0^1 \sqrt{1-x^2}\, \mathrm{d}x$$

$\displaystyle\int_0^1 \sqrt{1-x^2}\, \mathrm{d}x$ 表示单位圆在第一象限部分的面积，即 $\dfrac{\pi}{4}$。

因此 $\displaystyle\int_0^1 \dfrac{1}{f(x)}\,\mathrm{d}x = -\dfrac{\pi}{4}$。

答案为 **(C)**。

<!-- q {"id": "calc-ch08-q12", "type": "练习", "tags": ["积分"], "title": "严格上凸函数的反函数积分范围"} -->

<!-- stem -->
设 $f(x)$ 在 $[0,2]$ 上单调连续，$f(0) = 1$，$f(2) = 2$，且对任意 $x_1, x_2 \in [0,2]$ 总有 $f\left(\dfrac{x_1 + x_2}{2}\right) > \dfrac{f(x_1) + f(x_2)}{2}$，$g(x)$ 是 $f(x)$ 的反函数，$P = \displaystyle\int_1^2 g(x)\, \mathrm{d}x$，则（ ）

- (A) $3 < P < 4$
- (B) $2 < P < 3$
- (C) $1 < P < 2$
- (D) $0 < P < 1$

<!-- answer -->
由条件 $f\left(\dfrac{x_1 + x_2}{2}\right) > \dfrac{f(x_1) + f(x_2)}{2}$，知 $f(x)$ 是**严格上凸函数**。

又 $f(0) = 1 < f(2) = 2$，所以 $f(x)$ 在 $[0,2]$ 上**单调递增**。

反函数 $g(x)$ 满足：$g(1) = 0$，$g(2) = 2$。

由于 $f$ 上凸，其反函数 $g$ 为**下凸函数**。

**几何分析：**

$\displaystyle\int_1^2 g(x)\, \mathrm{d}x$ 表示曲线 $y = g(x)$ 在 $[1,2]$ 上与 $x$ 轴围成的面积。

由于 $g$ 下凸，曲线位于连接 $(1,0)$ 和 $(2,2)$ 的线段**下方**。

线段下方三角形面积 $= \dfrac{1}{2} \times 1 \times 2 = 1$。

又 $g(x) > 0$（当 $x > 1$ 时），所以 $0 < P < 1$。

答案为 **(D)**。

**【提示】** 反函数积分的几何意义：$\displaystyle\int_a^b f(x)\,\mathrm{d}x + \int_{f(a)}^{f(b)} g(y)\, \mathrm{d}y = b \cdot f(b) - a \cdot f(a)$，其中 $g$ 是 $f$ 的反函数。

<!-- q {"id": "calc-ch08-q13", "type": "练习", "tags": ["积分"], "title": "含参数 p 的反常积分收敛条件"} -->

<!-- stem -->
若反常积分 $\displaystyle\int_0^{+\infty} \dfrac{\ln x}{(1+x)\, x^{1-p}}\, \mathrm{d}x$ 收敛，则（ ）

- (A) $p < 1$
- (B) $p > 1$
- (C) $0 < p < 1$
- (D) $0 \le p < 1$

<!-- answer -->
将积分拆分为 $\displaystyle\int_0^1$ 和 $\displaystyle\int_1^{+\infty}$ 两部分分析敛散性。

**在 $x \to 0^+$ 处：**

被积函数 $\sim \dfrac{\ln x}{x^{1-p}} = x^{p-1} \ln x$。

当 $p > 0$ 时，$x^{p-1} \ln x \to 0$（$x \to 0^+$），积分收敛。

当 $p \le 0$ 时，$x^{p-1} \to +\infty$，且 $\ln x \to -\infty$，积分发散。

**在 $x \to +\infty$ 处：**

被积函数 $\sim \dfrac{\ln x}{x^{1-p} \cdot x} = \dfrac{\ln x}{x^{2-p}}$。

当 $2 - p > 1$，即 $p < 1$ 时，积分收敛。

当 $p \ge 1$ 时，积分发散。

**综合：** 需同时满足 $p > 0$ 且 $p < 1$，即 $0 < p < 1$。

答案为 **(C)**。
