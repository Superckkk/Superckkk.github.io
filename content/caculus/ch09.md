求不定积分$\displaystyle\int \frac{\sqrt{x}}{\sqrt{4-x^3}}\, \mathrm{d}x$

<!-- answer -->
$$\int \frac{\sqrt{x}}{\sqrt{4-x^3}}\, \mathrm{d}x = \frac{2}{3} \int \frac{\mathrm{d}\left(x^{3/2}\right)}{\sqrt{4-\left(x^{3/2}\right)^2}} = \frac{2}{3} \int \frac{\mathrm{d}\left(x^{3/2}\right)}{2\sqrt{1 - \left(\frac{1}{2} x^{3/2}\right)^2}} = \frac{2}{3} \arcsin\left(\frac{1}{2} x^{3/2}\right) + C$$

<!-- stem -->
求不定积分$\displaystyle\int \frac{x e^{\arctan x}}{\left(1+x^2\right)^{3/2}}\, \mathrm{d}x$

<!-- answer -->
$e^{\arctan x}$较为复杂,因此优先考虑三角代换：令$x = \tan t$,则原积分式变为：

$$\int \sin t\, e^t\, \mathrm{d}t = e^t \sin t - \int e^t \cos t\, \mathrm{d}t = e^t \sin t - e^t \cos t - \int e^t \sin t\, \mathrm{d}t$$

故原式$\displaystyle\int e^t \sin t\, \mathrm{d}t = \frac{1}{2} e^t (\sin t - \cos t) = \frac{(x-1)e^{\arctan x}}{2 \sqrt{1+x^2}} + C$

<!-- stem -->
计算不定积分$\displaystyle\int e^{2x}\left(\tan x + 1\right)^2 \mathrm{d}x$

<!-- answer -->
$$\begin{aligned}
\int e^{2x} (\tan x + 1)^2 \mathrm{d}x &= \int e^{2x} \left(\sec^2 x + 2 \tan x\right) \mathrm{d}x\\
&= \int e^{2x} \sec^2 x\, \mathrm{d}x + 2 \int e^{2x} \tan x\, \mathrm{d}x\\
&= \int e^{2x}\, \mathrm{d}(\tan x) + 2 \int e^{2x} \tan x\, \mathrm{d}x\\
&= e^{2x} \tan x - 2 \int e^{2x} \tan x\, \mathrm{d}x + 2 \int e^{2x} \tan^2 x\, \mathrm{d}x = e^{2x} \tan x + C
\end{aligned}$$

<!-- stem -->
求不定积分$\displaystyle\int \frac{4x^2 - 6x - 1}{(x+1)(2x-1)^2}\, \mathrm{d}x$

<!-- answer -->
按照上面给出的拆分方法，原积分式应当可以分解为：

$$\frac{4x^2 - 6x - 1}{(x+1)(2x-1)^2} = \frac{A_1}{x+1} + \frac{A_2}{2x-1} + \frac{A_3}{(2x-1)^2}$$

解方程可得：$A_1 = 1, A_2 = 0, A_3 = -2$,因此

$$\int \frac{4x^2 - 6x - 1}{(x+1)(2x-1)^2}\, \mathrm{d}x = \int \frac{1}{x+1}\, \mathrm{d}x + \int \frac{-2}{(2x-1)^2}\, \mathrm{d}x = \ln|x+1| + \frac{1}{2x-1} + C$$

<!-- stem -->
求不定积分$\displaystyle\int \frac{2x+3}{x^2 - x + 1}\, \mathrm{d}x$

<!-- answer -->
<mark>注意到:$\left(x^2 - x + 1\right)' = 2x - 1$</mark>,因此

$$\begin{aligned}
\int \frac{2x-3}{x^2 - x + 1}\, \mathrm{d}x = \int \frac{2x-1 + 4}{x^2 - x + 1}\, \mathrm{d}x &= \int \frac{1}{x^2 - x + 1}\, \mathrm{d}\left(x^2-x+1\right) + 4 \int \frac{1}{x^2 - x + 1}\, \mathrm{d}x\\
&= \ln\left|x^2-x+1\right| + 4 \int \frac{1}{\left(x-\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2}\, \mathrm{d}\left(x-\frac{1}{2}\right)\\
&= \ln\left|x^2-x+1\right| + 4 \left(\frac{2\sqrt{3}}{3} \arctan\left(\frac{2\sqrt{3}}{3} x - \frac{\sqrt{3}}{3}\right)\right) + C
\end{aligned}$$

<!-- stem -->
$\lim\limits_{n\to\infty} \dfrac{1}{n} \sum\limits_{i=1}^n \left[\ln(3n-2i) - \ln(n+2i)\right] = ＿＿＿.$

<!-- answer -->
$$\begin{aligned}
\lim_{n\to\infty} \frac{1}{n} \sum_{i=1}^n \left[\ln(3n-2i) - \ln(n+2i)\right] &= \lim_{n\to\infty} \sum_{i=1}^n \frac{1}{n} \ln\left(\frac{3n-2i}{n+2i}\right) = \int_0^1 \ln\left(\frac{3-2x}{1+2x}\right) \mathrm{d}x\\
&= x \ln\left(\frac{3-2x}{1+2x}\right) \Big|^1_0 + 8 \int_0^1 \frac{x}{(3-2x)(1+2x)}\, \mathrm{d}x\\
&= -\ln 3 + 8 \int_0^1 \left(\frac{3}{8(3-2x)} - \frac{1}{8(1+2x)}\right) \mathrm{d}x\\
&= -\ln 3 + \ln 3 = 0
\end{aligned}$$

**【提示】** 实际计算过就会发现,这样的计算相当之繁琐，那有没有更加巧妙的办法呢？答案是肯定的：

$$\int_0^1 \ln\left(\frac{3-2x}{1+2x}\right) \mathrm{d}x = \int_0^1 \ln\left(\frac{3/2 -x}{1/2 + x}\right) \mathrm{d}x = \int_{-1/2}^{1/2} \ln\left(\frac{1-t}{1+t}\right) \mathrm{d}t = 0 \quad \text{（奇函数的积分性质）}$$

<!-- stem -->
$\displaystyle\int_0^1 \arcsin\left(\sqrt{1-x^2}\right) \mathrm{d}x = ＿＿＿$

<!-- answer -->
令$x = \cos t$

$$\int_0^1 \arcsin\left(\sqrt{1-x^2}\right) \mathrm{d}x = \int_{-\pi/2}^0 -t\, \mathrm{d}(\cos t) = -t \cos t \Big|_{-\pi/2}^0 + \int_{-\pi/2}^0 \cos t\, \mathrm{d}t = 1$$

<!-- stem -->
$\displaystyle\int_0^1 x\, \arcsin\left(\sqrt{4x - 4x^2}\right) \mathrm{d}x = ＿＿＿$

<!-- answer -->
注意到:$4x-4x^2 = 1 - (1-2x)^2$,令$1-2x = t$, 则 $x = \dfrac{1-t}{2}$

$$\begin{aligned}
\int_0^1 x\, \arcsin\left(\sqrt{4x-4x^2}\right) \mathrm{d}x &= - \frac{1}{2} \int_1^{-1} \frac{1-t}{2} \arcsin\left(\sqrt{1-t^2}\right) \mathrm{d}t\\
&= - \frac{1}{4} \left[\int_{-1}^1 t\, \arcsin\left(\sqrt{1-t^2}\right) \mathrm{d}t - \int_{-1}^1 \arcsin\left(\sqrt{1-t^2}\right) \mathrm{d}t\right]\\
&= \frac{1}{4} \int_{-1}^1 \arcsin\left(\sqrt{1-t^2}\right) \mathrm{d}t\\
&= \frac{1}{2} \int_0^1 \arcsin\left(\sqrt{1-t^2}\right) \mathrm{d}t = \frac{1}{2}
\end{aligned}$$

**【重点】**

解出本题的关键在于：

1. 将$t\, \arcsin\left(\sqrt{1-t^2}\right)$和$\arcsin\left(\sqrt{1-t^2}\right)$分开求积分
2. 意识到$t\, \arcsin\left(\sqrt{1-t^2}\right)$是奇函数,$\arcsin\left(\sqrt{1-t^2}\right)$是偶函数
3. <mark>时刻注意积分变量的积分上下限</mark>

<!-- q {"id": "calc-ch09-q10", "type": "练习", "tags": ["积分的计算"], "title": "|sin x − sin t| 变限积分的泰勒多项式"} -->

<!-- stem -->
$F(x) = \displaystyle\int_0^{\pi/2} \left|\sin x - \sin t\right| \mathrm{d}t \ \left(x \ge 0\right)$在$x \to 0^+$处的二次泰勒多项式为$a + b x + c x^2,$则$a\, b\, c = ＿＿＿.$

<!-- answer -->
$x > t$时$\left|\sin x - \sin t\right| = \sin x - \sin t$,$x < t$时$\left|\sin x - \sin t\right| = \sin t - \sin x$

$$\begin{aligned}
F(x) &= \int_0^{\pi/2} \left|\sin x - \sin t\right| \mathrm{d}t\\
&= \int_0^x (\sin x - \sin t)\, \mathrm{d}t + \int_x^{\pi/2} (\sin t - \sin x)\, \mathrm{d}t\\
&= \int_0^x \sin x\, \mathrm{d}t - \int_x^{\pi/2} \sin x\, \mathrm{d}t - \int_0^x \sin t\, \mathrm{d}t + \int_x^{\pi/2} \sin t\, \mathrm{d}t\\
&= \sin x \left[x - \left(\frac{\pi}{2} - x\right)\right] + (\cos x - \cos 0) - \left(\cos \frac{\pi}{2} - \cos x\right)\\
&= \left(2x - \frac{\pi}{2}\right)\sin x + 2 \cos x - 1
\end{aligned}$$

- $\sin x = x - \dfrac{x^3}{6} + o(x^3)$
- $\cos x = 1 - \dfrac{x^2}{2} + o(x^2)$

因此$F(x) = 1 - \dfrac{\pi}{2} x + x^2 + o(x^2), \ a\, b\, c = -\dfrac{\pi}{2}$

<!-- q {"id": "calc-ch09-q11", "type": "练习", "tags": ["积分的计算"], "title": "被积函数含参数 x 的变限积分"} -->

<!-- stem -->
设函数$f(x)$可导,且$f(x) < -2 x f'(x)$,则曲线$F(x) = \displaystyle\int_0^x t f\left(x^2 - t^2\right) \mathrm{d}t$ （ ）

- (A) 在$x=0$处取极大值
- (B) 在$x=0$处取极小值
- (C) 拐点是$(0,0)$
- (D) 在$(0,0)$处既非极值点也非拐点

<!-- answer -->
$$F(x) = \int_0^x t f\left(x^2 - t^2\right) \mathrm{d}t = \frac{1}{2} \int_0^x f\left(x^2 - t^2\right) \mathrm{d}\left(t^2\right) = \frac{1}{2} \int_x^0 f\left(x^2 - t^2\right) \mathrm{d}\left(x^2 - t^2\right)$$

令$x^2 - t^2 = u$,则

$$\begin{aligned}
&F(x) = \frac{1}{2} \int_0^{x^2} f(u)\, \mathrm{d}u, \quad F(0) = 0\\
&F'(x) = \frac{1}{2} f\left(x^2\right) \cdot 2x = x f\left(x^2\right), \quad F'(0) = 0\\
&F''(x) = f\left(x^2\right) + 2x^2 f'\left(x^2\right) < 0
\end{aligned}$$

因为$F(0) = F'(0) = 0, F''(0) < 0$,故$x = 0$是一个极大值点,答案为(A)

**【问答】**

**$u = x^2 - t^2$同时包含参数$x$和积分变量$t$,凭什么换完之后$x$就只出现在上限、而从被积函数中消失了？这样做求导不会丢失对$x$的依赖吗？**

把$x$想象成$x=3$,积分变成$\int_0^3 t f(9-t^2)\,\mathrm{d}t$,令$u = 9-t^2$,这就是一个最普通的、毫无争议的换元.既然对于每一个确定的$x$值,换元$u = x^2 - t^2$都是一个合法的标准定积分换元,那么我们就可以得到：

$$F(x) = \frac{1}{2} \int_0^{x^2} f(u)\, \mathrm{d}u$$

而实际上,$x$对积分的影响并未消失，其从被积函数转移到了积分上限中，总的依赖关系仍然存在。

**【推论（莱布尼茨积分求导公式）】**

此前所说的"只有当被积函数中只包含"积分变量"时，才能使用变限积分的求导公式求导"实则是一个简化版本，对于更一般的情况，我们可以使用莱布尼茨积分求导公式计算：

$$\begin{aligned}
&F(x) = \int_{\psi(x)}^{\phi(x)} f(x,t)\, \mathrm{d}t\\
&F'(x) = f(x,\phi(x))\phi'(x) - f(x,\psi(x)) \psi'(x) + \int_{\psi(x)}^{\phi(x)} \frac{\partial f}{\partial x}(x,t)\, \mathrm{d}t
\end{aligned}$$

<!-- stem -->
计算反常积分$\displaystyle\int_{1/2}^{3/2} \frac{1}{\sqrt{\left|x - x^2\right|}}\, \mathrm{d}x$

<!-- answer -->
被积函数的瑕点为$x = 1,$该点同时为绝对值中函数的零点，因此可以以该点拆分积分区间：

$$\begin{aligned}
\int_{1/2}^{3/2} \frac{1}{\sqrt{\left|x - x^2\right|}}\, \mathrm{d}x &= \int_{1/2}^1 \frac{1}{\sqrt{x-x^2}}\, \mathrm{d}x + \int_1^{3/2} \frac{1}{\sqrt{x^2 - x}}\, \mathrm{d}x\\
&= \int_{1/2}^1 \frac{1}{\sqrt{\frac{1}{4} - \left(x-\frac{1}{2}\right)^2}}\, \mathrm{d}x + \int_1^{3/2} \frac{1}{\sqrt{\left(x-\frac{1}{2}\right)^2 - \frac{1}{4}}}\, \mathrm{d}x\\
&= \int_0^{1/2} \frac{1}{\sqrt{\frac{1}{4} - x^2}}\, \mathrm{d}x + \int_{1/2}^1 \frac{1}{\sqrt{x^2 - \frac{1}{4}}}\, \mathrm{d}x\\
&= \arcsin(2x) \Big|^{\frac{1}{2}}_0 + \ln\left(x + \sqrt{x^2 - \frac{1}{4}}\right) \Big|^1_{\frac{1}{2}}\\
&= \frac{\pi}{2} + \ln\left(2+\sqrt{3}\right)
\end{aligned}$$

<!-- q {"id": "calc-ch09-q13", "type": "练习", "tags": ["积分的计算"], "title": "Iₙ = ∫₀^∞ xⁿe^{−x} dx"} -->

<!-- stem -->
计算$I_n = \displaystyle\int_0^{+\infty} x^n e^{-x}\, \mathrm{d}x$

<!-- answer -->
$$\begin{aligned}
I_n &= \int_0^{+\infty} \frac{1}{n+1} \cdot \frac{1}{e^x}\, \mathrm{d}\left(x^{n+1}\right)\\
&= \left. \frac{x^{n+1}}{(n+1)\, e^x} \right|^{+\infty}_0 + \frac{1}{n+1} \int_0^{+\infty} x^{n+1} e^{-x}\, \mathrm{d}x\\
&= 0 + \frac{1}{n+1} \cdot I_{n+1}
\end{aligned}$$

因此由递推关系可得 $I_n = \left(\displaystyle\prod_{i=1}^{n} i\right) I_0 = n!$（$I_0 = 1$）

**【推论（Tau 函数）】**

$$\operatorname{Tau}(\alpha) = \int_0^{+\infty} x^{\alpha-1} e^{-x}\,\mathrm{d}x$$

1. $\operatorname{Tau}(1) = 1$
2. $\operatorname{Tau}\left(\dfrac{1}{2}\right) = \sqrt{\pi}$
3. $\operatorname{Tau}(\alpha+1) = \alpha \operatorname{Tau}(\alpha)$

<!-- stem -->
求$\displaystyle\int \max\left(1, \left|x\right|\right) \mathrm{d}x$

<!-- answer -->
思路和计算都十分简单，关键是要注意细节：

- $x > 1$时：原式$= \displaystyle\int x\, \mathrm{d}x = \frac{x^2}{2}$<mark>$+C_1$</mark>
- $x < -1$时：原式$= \displaystyle\int -x\, \mathrm{d}x = -\frac{x^2}{2}$<mark>$+C_2$</mark>
- $-1 \le x \le 1$时：原式$= x$<mark>$+C_3$</mark>

由于我们需要保证原函数连续，因此有：

$$\begin{cases} \dfrac{1}{2} + C_1 = 1 + C_3\\ -\dfrac{1}{2} + C_2 = -1 + C_3 \end{cases}$$

一个可行解为$C_1 = \dfrac{1}{2}, C_2 = -\dfrac{1}{2}, C_3 = 0$,因此

$$\int \max\left(1, \left|x\right|\right) \mathrm{d}x = \begin{cases} \dfrac{x^2}{2} + \dfrac{1}{2} & x > 1\\ x & -1 \le x \le 1\\ -\dfrac{x^2}{2} - \dfrac{1}{2} & x < -1 \end{cases}$$

<!-- q {"id": "calc-ch09-q16", "type": "练习", "tags": ["积分的计算"], "title": "∫₀^{3π/4} 1/(1+cos²x) dx"} -->

<!-- stem -->
求定积分$\displaystyle\int_0^{\frac{3}{4}\pi} \frac{1}{1+\cos^2 x}\, \mathrm{d}x$

<!-- answer -->
<mark>$$\frac{1}{1+\cos^2 x} = \frac{\frac{1}{\cos^2 x}}{\frac{1}{\cos^2 x} + 1} = \frac{\sec^2 x}{2 + \tan^2 x}$$</mark>

所以原式$= \displaystyle\int_0^{\frac{3}{4}\pi} \frac{\sec^2 x}{2 + \tan^2 x}\, \mathrm{d}x = \int_0^{\frac{3}{4}\pi} \frac{1}{2 + \tan^2 x}\, \mathrm{d}(\tan x)$

我们在换元时必须时刻注意积分区间和积分变量的种种细节。在这个积分式中,积分区间是$\left[0, \frac{3}{4}\pi\right]$,积分变量是$\tan x$,注意到在$x = \dfrac{1}{2}\pi$时,$\tan x$是无定义的,因此我们需要拆分积分区间：

$$\begin{aligned}
&\int_0^{\frac{3}{4}\pi} \frac{1}{2 + \tan^2 x}\, \mathrm{d}(\tan x) = \int_0^{\frac{1}{2}\pi} \frac{1}{2 + \tan^2 x}\, \mathrm{d}(\tan x) + \int_{\frac{1}{2}\pi}^{\frac{3}{4}\pi} \frac{1}{2 + \tan^2 x}\, \mathrm{d}(\tan x)\\
&\int \frac{1}{2 + \tan^2 x}\, \mathrm{d}(\tan x) = \frac{1}{\sqrt{2}} \int \frac{1}{1 + \left(\frac{\tan x}{\sqrt{2}}\right)^2}\, \mathrm{d}\left(\frac{\tan x}{\sqrt{2}}\right) = \frac{1}{\sqrt{2}} \arctan\left(\frac{\tan x}{\sqrt{2}}\right) = F(x)
\end{aligned}$$

$$\begin{aligned}
\int_0^{\frac{3}{4}\pi} \frac{1}{2 + \tan^2 x}\, \mathrm{d}(\tan x) &= \lim_{x\to \left(\frac{1}{2}\pi\right)^-} F(x) - F(0) + F\left(\frac{3}{4}\pi\right) - \lim_{x\to \left(\frac{1}{2}\pi\right)^+} F(x)\\
&= \frac{\pi}{\sqrt{2}} - \frac{1}{\sqrt{2}} \arctan\left(\frac{1}{\sqrt{2}}\right)
\end{aligned}$$

<!-- q {"id": "calc-ch09-q17", "type": "练习", "tags": ["积分的计算"], "title": "∫ e^{x/2}(cos x−sin x)/√(cos x) dx"} -->

<!-- stem -->
计算$\displaystyle\int_{-\frac{\pi}{4}}^{\frac{\pi}{4}} e^{\frac{x}{2}} \frac{\cos x - \sin x}{\sqrt{\cos x}}\, \mathrm{d}x$

<!-- answer -->
$$\begin{aligned}
\int_{-\pi/4}^{\pi/4} e^{x/2} \frac{\cos x - \sin x}{\sqrt{\cos x}}\, \mathrm{d}x &= \int_{-\pi/4}^{\pi/4} e^{x/2} \sqrt{\cos x}\, \mathrm{d}x - \int_{-\pi/4}^{\pi/4} e^{x/2} \frac{\sin x}{\sqrt{\cos x}}\, \mathrm{d}x\\
