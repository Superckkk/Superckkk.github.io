<!-- q {"id": "calc-ch15-q1", "type": "练习", "tags": ["微分方程"], "title": "由通解结构求 lim φ(x)"} -->

<!-- stem -->
设函数$y = \phi(x)$是微分方程$y' + e y = \left(1- \dfrac{1}{x}\right)^x$的一个解,则$\lim\limits_{x\to +\infty} \phi(x) = ＿＿＿.$

<!-- answer -->
$p = e, \ q = \left(1-\frac{1}{x}\right)^x, \ \mu = e^{\int p(x)\,\mathrm{d}x} = e^{e x}$,则:

$$\begin{aligned}
\phi(x) &= e^{- e x} \left[\int e^{e x} \cdot \left(1-\frac{1}{x}\right)^x \mathrm{d}x + C\right] = \frac{\int e^{e x} \cdot \left(1-\frac{1}{x}\right)^x \mathrm{d}x + C}{e^{e x}}\\
\lim_{x\to +\infty} \phi(x) &= \lim_{x\to +\infty} \frac{\int e^{e x} \cdot \left(1-\frac{1}{x}\right)^x \mathrm{d}x}{e^{e x}} = \lim_{x\to +\infty} \frac{e^{e x} \cdot \left(1-\frac{1}{x}\right)^x}{e \cdot e^{e x}} = \frac{1}{e^2}
\end{aligned}$$

需要注意的是:我们需要指出,由于被积函数指数增长,所以当$x\to +\infty$时,$\int e^{e x} \cdot \left(1-\frac{1}{x}\right)^x \mathrm{d}x$也是趋于无穷的,因此可以使用洛必达法则.如果觉得这样不严谨,也可以将不定积分$\int e^{e x} \cdot \left(1-\frac{1}{x}\right)^x \mathrm{d}x$改写为定积分$\int_{x_0}^x e^{e t} \cdot \left(1-\frac{1}{t}\right)^t \mathrm{d}t$的形式,这样当$x\to +\infty$时自然得出定积分也趋于正无穷大.

<!-- q {"id": "calc-ch15-q2", "type": "练习", "tags": ["微分方程"], "title": "y″=y′[1+(y′)²] 的特解"} -->

<!-- stem -->
求微分方程$y''= y'\left[1+\left(y'\right)^2\right]$满足$y(0) = 0, y'(0) = 1$的特解

<!-- answer -->
先分析其属于那种类型:方程中既不显含$x$又不显含$y$,则令$y' = p, \ y'' = p'$,原方程变为:

$$p' = p\left(1+p^2\right) = \frac{\mathrm{d}p}{\mathrm{d}x}$$

则:

$$\begin{aligned}
\frac{1}{p\left(1+p^2\right)}\, \mathrm{d}p &= \mathrm{d}x\\
\int \frac{1}{p\left(1+p^2\right)}\, \mathrm{d}p &= x + C\\
\ln \frac{p^2}{1+p^2} &= 2 x + \ln C_1
\end{aligned}$$

依题意:$y'(0) = 1 \Longrightarrow x = 0$时$p = 1$,代入解得:$C_1 = \dfrac{1}{2}$则:

$$\begin{aligned}
y' &= p = \frac{\frac{e^x}{\sqrt{2}}}{\sqrt{1 - \frac{1}{2} e^{2x}}}\\
y &= \int \frac{\frac{e^x}{\sqrt{2}}}{\sqrt{1 - \frac{1}{2} e^{2x}}}\, \mathrm{d}x = \arcsin\left(\frac{e^x}{\sqrt{2}}\right) + C_2
\end{aligned}$$

又依题意:$y(0) = 0,$解得$C_2 = - \dfrac{\pi}{4}$,故$y = \arcsin\left(\dfrac{e^x}{\sqrt{2}}\right) - \dfrac{\pi}{4}$

<!-- q {"id": "calc-ch15-q3", "type": "练习", "tags": ["微分方程"], "title": "含 f′(x) 的全微分方程"} -->

<!-- stem -->
求满足$f(0) = 0$的具有一阶连续导数的$f(x)$,使$\left[y f'(x) + y^2\right] \mathrm{d}x + \left(x^2 + 2 x y\right) \mathrm{d}y = 0$为全微分方程,并求此全微分方程的解

<!-- answer -->
由定义,有:

$$\frac{\partial\left(x^2 + 2 x y\right)}{\partial x} = \frac{\partial\left(y f'(x) + y^2\right)}{\partial y}$$

即:

$$2x+2y = f'(x) + 2y$$

故$f'(x) = 2 x, \ f(x) = x^2 + C$.由$f(0) = 0$得$C = 0$.于是有:

$$\left(2x y + y^2\right) \mathrm{d}x + \left(x^2 + 2 x y\right) \mathrm{d}y = \mathrm{d}\left(x^2 y + x y^2\right) = 0$$

故通解为$x^2 y + x y^2 = C$,$C$为任意常数

<!-- q {"id": "calc-ch15-q4", "type": "练习", "tags": ["微分方程"], "title": "切线与法线截距之比 3:1 的曲线"} -->

<!-- stem -->
已知曲线上任一点的切线在$y$轴上的截距与法线在$x$轴上的截距之比为$3:1$,则该曲线方程为＿＿＿

<!-- answer -->
已知,曲线上任意一点$\left(x_0, y_0\right)$处的切线和法线方程分别为:

$$\begin{aligned}
y - y(x_0) &= y'(x_0) \left(x - x_0\right)\\
y - y(x_0) &= - \frac{1}{y'(x_0)} \left(x - x_0\right)
\end{aligned}$$

因此切线在$y$轴上的截距与法线在$x$轴上的截距分别为$y(x_0) - y'(x_0)\, x_0$和$x_0 + y(x_0)\, y'(x_0)$,依题意:

$$\begin{aligned}
\frac{y - y'x}{x + y y'} = 3 \quad \text{令 } u = y/x \Longrightarrow -u'x &= 3u^2 + 3 u x u' + 3\\
u'x &= -3\, \frac{u^2 + 1}{3u+1}\\
\frac{3u+1}{u^2+1}\, \mathrm{d}u &= -\frac{3}{x}\, \mathrm{d}x\\
\frac{3}{2} \int \frac{1}{u^2 + 1}\, \mathrm{d}\left(u^2\right) + \int \frac{1}{u^2+1}\, \mathrm{d}u &= -3 \int \frac{1}{x}\, \mathrm{d}x\\
\frac{3}{2} \ln\left(u^2+1\right) + \arctan(u) &= -3 \ln \left|x\right| + C\\
3 \ln \sqrt{\frac{y^2}{x^2} + 1} + \arctan \frac{y}{x} &= -3 \ln \sqrt{x^2} + C\\
\arctan \frac{y}{x} + 3 \ln \sqrt{x^2 + y^2} &= C
\end{aligned}$$

<!-- stem -->
求微分方程$\left(2x - 3x y^2 - y^3\right) y' + y^3 = 0$的通解

<!-- answer -->
原方程化为:

$$\begin{aligned}
\frac{\mathrm{d}y}{\mathrm{d}x} &= - \frac{y^3}{2x - 3x y^2 - y^3}\\
\frac{\mathrm{d}x}{\mathrm{d}y} &= - \frac{2x - 3x y^2 - y^3}{y^3} = \frac{3y^2 -2}{y^3} x + 1\\
\frac{\mathrm{d}x}{\mathrm{d}y} + \frac{2 - 3y^2}{y^3} x &= 1
\end{aligned}$$

这样,将$x$当作因变量,$y$当作自变量,整个微分方程变为一阶非线性齐次微分方程,可以使用公式求解
