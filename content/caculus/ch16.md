<!-- q {"id": "calc-ch16-q1", "type": "练习", "tags": ["无穷级数"], "title": "正项级数收敛的两个证明"} -->

<!-- stem -->
(1)设$\sum\limits_{n=1}^{\infty} u_n$是正项级数,若$\sum\limits_{n=1}^{\infty} \sqrt{u_n u_{n+1}}$收敛,且$\{u_n\}$单调减少,证明:$\sum\limits_{n=1}^{\infty} u_n$收敛

(2)设$\sum\limits_{n=1}^{\infty} u_n$和$\sum\limits_{n=1}^{\infty} v_n$都是正项级数,且$\sum\limits_{n=1}^{\infty} u_n$和$\sum\limits_{n=1}^{\infty} v_n$都收敛,证明:$\sum\limits_{n=1}^{\infty} u_n v_n$收敛

<!-- answer -->
(1)

$\{u_n\}$单调减少,说明$u_{n+1} < u_n$,因此$\sqrt{u_n u_{n+1}} > u_{n+1}$,$\sum\limits_{n=1}^{\infty} \sqrt{u_n u_{n+1}} > \sum\limits_{n=2}^{\infty} u_n$,因此$\sum\limits_{n=1}^{\infty} u_n$收敛

(2)

**【提示】** 正项级数$\sum\limits_{n=1}^{\infty} u_n$收敛,则$\sum\limits_{n=1}^{\infty} u_n^a$收敛,$a > 1$

**【证明】** $\sum\limits_{n=1}^{\infty} u_n$收敛,则$\lim\limits_{n\to\infty} u_n = 0 \Longrightarrow \forall M > 0, \ \exists N,$ 当 $n > N,$ 有 $u_n < M$.因此

$$u_n^a = u_n \cdot u_n^{a-1} < u_n \cdot M^{a-1}$$

$\sum\limits_{n=1}^{\infty} u_n^a < M^{a-1} \sum\limits_{n=1}^{\infty} u_n \Longrightarrow \sum\limits_{n=1}^{\infty} u_n^a$收敛

因此,$\sum\limits_{n=1}^{\infty} u_n$和$\sum\limits_{n=1}^{\infty} v_n$收敛,则$\sum\limits_{n=1}^{\infty} u_n^2, \sum\limits_{n=1}^{\infty} v_n^2$也收敛. $v_n u_n < \dfrac{u_n^2 + v_n^2}{2}$,因此$\sum\limits_{n=1}^{\infty} u_n v_n$收敛.

<!-- q {"id": "calc-ch16-q2", "type": "练习", "tags": ["无穷级数"], "title": "xⁿ+nx−1=0 的正实根与级数收敛"} -->

<!-- stem -->
设有方程$x^n + n x -1 =0$,其中$n$为正整数.证明此方程存在唯一的正实根$x_n$,并证明当$a>1$时,级数$\sum\limits_{n=1}^{\infty} x_n^a$收敛

<!-- answer -->
记$f_n = x^n + n x - 1$,则$f(0) = -1 < 0, f(1) = n > 0$. $f'(x) = n x^{n-1} + n$在$[0, +\infty)$上大于0,根据零点存在定理,$f(x)$在$[0, +\infty)$上有唯一的正实根$x_n$.

$$x_n^n + n x_n - 1 = 0 \Longrightarrow x_n = \frac{1 - x_n^n}{n} < \frac{1}{n}$$

因此$x_n^a < \dfrac{1}{n^a}$,由于$a > 1$,$\sum\limits_{n=1}^{\infty} \dfrac{1}{n^a}$收敛,故$\sum\limits_{n=1}^{\infty} x_n^a$收敛。

<!-- q {"id": "calc-ch16-q3", "type": "练习", "tags": ["无穷级数"], "title": "∑sin(n^{-α}ln n) 收敛时 α 的范围"} -->

<!-- stem -->
设$\alpha > 0$,级数$\sum\limits_{n=2}^{\infty} \sin\left(n^{-\alpha} \ln n\right)$收敛,则$\alpha$的取值范围为:

<!-- answer -->
$\lim\limits_{n\to\infty} n^{-\alpha} \ln n = 0 \Longrightarrow \lim\limits_{n\to\infty} \dfrac{\sin\left(n^{-\alpha} \ln n\right)}{n^{-\alpha} \ln n} = 1$,因此$\sum\limits_{n=2}^{\infty} \sin\left(n^{-\alpha} \ln n\right)$的敛散性与$\sum\limits_{n=1}^{\infty} n^{-\alpha} \ln n$相同.

- $0 < \alpha \le 1$时,当$n$足够大,有$n^{-\alpha} \ln n > n^{-\alpha}$,而$\sum\limits_{n=2}^{\infty} n^{-\alpha}$发散,故原级数也发散
- $\alpha > 1$时,总存在足够小的$\epsilon > 0$,使得$\alpha - \epsilon > 1$,因此有$\lim\limits_{n\to\infty} \dfrac{n^{-\alpha} \ln n}{n^{-\alpha+ \epsilon}} = \lim\limits_{n\to\infty} \dfrac{\ln n}{n^{\epsilon}} = 0$,而$\sum\limits_{n=1}^{\infty} n^{-\alpha + \epsilon}$收敛,故原级数收敛.

因此$\alpha$的取值范围为$(1, \infty)$

<!-- q {"id": "calc-ch16-q4", "type": "练习", "tags": ["无穷级数"], "title": "含 sin² 与 cos 幂的级数敛散性"} -->

<!-- stem -->
级数$\sum\limits_{n=1}^{\infty} \left[e^{\frac{\sin^2 \alpha n}{n^2}} + \left(\cos \dfrac{1}{\sqrt{n}}\right)^{n^2} - 1\right]$的敛散性如何

<!-- answer -->
分别考虑$e^{\frac{\sin^2 \alpha n}{n^2}} - 1$和$\left(\cos \dfrac{1}{\sqrt{n}}\right)^{n^2}$两部分:

$$e^{\frac{\sin^2 \alpha n}{n^2}} - 1 \sim \frac{\sin^2 \alpha n}{n^2} \le \frac{1}{n^2} \Longrightarrow \text{收敛}$$

$$\lim_{n\to\infty} \sqrt[n]{\left(\cos \frac{1}{\sqrt{n}}\right)^{n^2}} = \lim_{n\to\infty} \left(\cos \frac{1}{\sqrt{n}}\right)^n \sim 1 - \frac{1}{2n} \cdot n = \frac{1}{2} < 1 \Longrightarrow \text{收敛}$$

故级数整体收敛

<!-- q {"id": "calc-ch16-q5", "type": "练习", "tags": ["无穷级数"], "title": "∑(−1)ⁿ/(√n+(−1)ⁿ) 的敛散性"} -->

<!-- stem -->
判断级数$\sum\limits_{n=2}^{+\infty} \dfrac{(-1)^n}{\sqrt{n} + (-1)^n}$的敛散性

<!-- answer -->
对于原级数:$u_n = \dfrac{1}{\sqrt{n} + (-1)^n}$,$u_{2k} = \dfrac{1}{\sqrt{2k} + 1}, \ u_{2k+1} = \dfrac{1}{\sqrt{2k+1} - 1}$,有:$u_{2k} < u_{2k+1}$,可见$u_n$并不单调收敛.因此莱布尼茨判别法失效.考虑拆项处理:

$$\frac{(-1)^n}{\sqrt{n} + (-1)^n} = \frac{(-1)^n \cdot \left(\sqrt{n} - (-1)^n\right)}{\left(\sqrt{n} + (-1)^n\right) \cdot \left(\sqrt{n} - (-1)^n\right)} = (-1)^n \cdot \frac{\sqrt{n} - (-1)^n}{n - 1} = (-1)^n \frac{\sqrt{n}}{n-1} - \frac{1}{n-1}$$

前一项为交错级数,易证其收敛,而后一项发散,故原级数整体发散

<!-- q {"id": "calc-ch16-q6", "type": "练习", "tags": ["无穷级数"], "title": "∑nuₙ 绝对收敛与 ∑vₙ/n 条件收敛"} -->

<!-- stem -->
若$\sum\limits_{n=1}^{\infty} n u_n$绝对收敛,$\sum\limits_{n=1}^{\infty} \dfrac{v_n}{n}$条件收敛,则：

- (A) $\sum\limits_{n=1}^{\infty} u_n v_n$条件收敛
- (B) $\sum\limits_{n=1}^{\infty} u_n v_n$绝对收敛
- (C) $\sum\limits_{n=1}^{\infty} \left(u_n + v_n\right)$收敛
- (D) $\sum\limits_{n=1}^{\infty} \left(u_n + v_n\right)$发散

<!-- answer -->
$\sum\limits_{n=1}^{\infty} \dfrac{v_n}{n}$条件收敛,则$\lim\limits_{n\to\infty} \dfrac{v_n}{n} = 0,$因此$\dfrac{v_n}{n}$有界,设$\left|\dfrac{v_n}{n}\right| < M$,则$\left|u_n v_n\right| = \left|n u_n \cdot \dfrac{v_n}{n}\right| \le M \left|n u_n\right|$,而$\sum\limits_{n=1}^{\infty} n u_n$绝对收敛,则$\sum\limits_{n=1}^{\infty} M \left|n u_n\right|$收敛,故推出$\sum\limits_{n=1}^{\infty} \left|u_n v_n\right|$收敛,因此$\sum\limits_{n=1}^{\infty} u_n v_n$绝对收敛.

C, D需要构造反例

<!-- stem -->

- (A) 绝对收敛
- (B) 条件收敛
- (C) 发散
- (D) 敛散性不确定

<!-- answer -->
$\sum\limits_{n=1}^{\infty} a_n (x+1)^n$在点$x = 1$处条件收敛$\Longrightarrow$$R = \left|1 - (-1)\right| = 2$,即:

对于级数$\sum\limits_{n=1}^{\infty} a_n x^n$,其收敛区间为$(-2,2)$,因此对于级数$\sum\limits_{n=1}^{\infty} a_n (x-1)^n$,其收敛区间为$(-1,3)$

求导后收敛半径不变,收敛域可能缩小,因此$\sum\limits_{n=1}^{\infty} n a_n (x-1)^{n-1}$的收敛域为$(-1,3)$,级数整体乘以$(x-1)$,收敛域不变,因此$\sum\limits_{n=1}^{\infty} n a_n (x-1)^n$的收敛域为$(-1,3)$,因此在$x = 2$处绝对收敛

因此答案选A

**【重点】**

已知级数$\sum\limits_{n=1}^{\infty} a_n \left(x - x_0\right)^n$的收敛半径为$R$,则收敛域为$\left(x_0 - R, x_0 + R\right)$,端点处额外判定.平移后的级数$\sum\limits_{n=1}^{\infty} a_n \left(x - x_1\right)^n$的收敛半径仍为$R$,收敛域平移至$\left(x_1 - R, x_1 + R\right)$.
