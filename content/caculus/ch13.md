<!-- q {"id": "calc-ch13-q1", "type": "练习", "tags": ["多元函数微分学"], "title": "I₁ 与 I₂ 的存在性"} -->

<!-- stem -->
设$I_1 = \lim\limits_{\substack{x\to 0\\ y\to 0}} \dfrac{\left|x y\right|}{\sqrt{x^2 + y^2}}, \quad I_2 = \lim\limits_{\substack{x\to 0\\ y\to 0}} \dfrac{x \left|y\right|}{x^2 + y^2}$,则（ ）

- (A) $I_1$存在,$I_2$不存在
- (B) $I_1$存在,$I_2$存在
- (C) $I_1$不存在,$I_2$存在
- (D) $I_1$不存在,$I_2$不存在

<!-- answer -->
$$0 \le I_1 = \lim_{\substack{x\to 0\\ y\to 0}} \frac{\left|x y\right|}{\sqrt{x^2 + y^2}} \le \lim_{\substack{x\to 0\\ y\to 0}} \frac{\frac{1}{2} \left(x^2 + y^2\right)}{\sqrt{x^2 + y^2}} = \lim_{\substack{x\to 0\\ y\to 0}} \frac{1}{2} \sqrt{x^2 + y^2} = 0$$

由夹逼准则,$I_1$存在,其值为0.

取路径$y = x$,则$I_2 = \lim\limits_{\substack{x\to 0\\ y\to x}} \dfrac{x \left|x\right|}{x^2 + x^2} = \lim\limits_{x\to 0} \dfrac{x \left|x\right|}{2x^2}$

$$\lim_{x\to 0^+} \frac{x \left|x\right|}{2x^2} = \frac{1}{2}, \quad \lim_{x\to 0^-} \frac{x \left|x\right|}{2x^2} = -\frac{1}{2}$$

故极限不存在,即$I_2$不存在

<!-- q {"id": "calc-ch13-q2", "type": "练习", "tags": ["多元函数微分学"], "title": "f′ₓ(1,+∞) 的两种求法"} -->

<!-- stem -->
设函数$f(x,y) = \displaystyle\int_0^{x y} e^{-x t^2}\, \mathrm{d}t,$则$f'_x\left(1, +\infty\right) = ＿＿＿$

<!-- answer -->
①

当$x > 0$时,令$u = \sqrt{x}\, t$

$$f(x,y) = \int_0^{x^{3/2} y} e^{-u^2} \frac{1}{\sqrt{x}}\, \mathrm{d}u = \frac{1}{\sqrt{x}} \int_0^{x^{3/2} y} e^{-u^2}\, \mathrm{d}u$$

因此$f(x, +\infty) = \lim\limits_{y\to +\infty} f(x,y) = \dfrac{1}{\sqrt{x}} \int_0^{+\infty} e^{-u^2}\, \mathrm{d}u = \dfrac{\sqrt{\pi}}{2} \cdot \dfrac{1}{\sqrt{x}}$

$$\begin{aligned}
f'_x(x, +\infty) &= \frac{\sqrt{\pi}}{2} \cdot \left(-\frac{1}{2} x^{-3/2}\right)\\
f'_x(1, +\infty) &= -\frac{\sqrt{\pi}}{4}
\end{aligned}$$

②

$$\begin{aligned}
\frac{\mathrm{d}\left(f(x,y)\right)}{\mathrm{d}x} &= e^{-x \cdot (x y)^2} \cdot y + \int_0^{x y} e^{-x t^2} \cdot \left(-t^2\right) \mathrm{d}t\\
\frac{\mathrm{d}\left(f(1, +\infty)\right)}{\mathrm{d}x} &= 0 - \int_0^{+\infty} e^{-t^2} \cdot t^2\, \mathrm{d}t\\
&= - \frac{1}{2} \int_0^{+\infty} e^{-t^2} \cdot t\, \mathrm{d}\left(t^2\right)\\
&= -\frac{1}{2} \int_0^{+\infty} \sqrt{u}\, e^{-u}\, \mathrm{d}u\\
&= -\frac{1}{2} \operatorname{Tau}\left(\frac{3}{2}\right) = - \frac{1}{2} \cdot \frac{1}{2} \cdot \operatorname{Tau}\left(\frac{1}{2}\right) = -\frac{\sqrt{\pi}}{4}
\end{aligned}$$

**【提示】（Tau 函数）**

- $\operatorname{Tau}(\alpha) = \displaystyle\int_0^{+\infty} x^{\alpha-1} e^{-x}\, \mathrm{d}x$
- $\operatorname{Tau}(\alpha+1) = \alpha \operatorname{Tau}(\alpha)$
- $\operatorname{Tau}(1) = 1$
- $\operatorname{Tau}\left(\dfrac{1}{2}\right) = \dfrac{\sqrt{\pi}}{2}$

<!-- q {"id": "calc-ch13-q3", "type": "练习", "tags": ["多元函数微分学"], "title": "由偏微分方程求 f(x,y)"} -->

<!-- stem -->
设函数$f(x,y)$可微,$f(0,0) = 0, \dfrac{\partial f}{\partial x} = - f(x,y), \dfrac{\partial f}{\partial y} = e^{-x} \cos y,$求$f(x,y)$

<!-- answer -->
$$\frac{\partial f}{\partial y} = e^{-x} \cos y \Longrightarrow f(x,y) = \int e^{-x} \cos y\, \mathrm{d}y + \phi(x) = e^{-x} \sin y + \phi(x)$$

$$\frac{\partial f}{\partial x} = - e^{-x} \sin y + \phi'(x) = - f(x,y) = - e^{-x} \sin y - \phi(x)$$

因此:

$$\phi'(x) = - \phi(x) \Longrightarrow \phi(x) = C e^{-x} \quad \text{（微分方程）}$$

故

$$f(x,y) = e^{-x} \sin y + C e^{-x}$$

又因为$f(0,0) = 0$,故$C = 0$

因此$f(x,y) = e^{-x} \sin y$

<!-- q {"id": "calc-ch13-q4", "type": "练习", "tags": ["多元函数微分学"], "title": "z = f(eˣsin y, x²+y²) 的混合偏导"} -->

<!-- stem -->
设$z = f\left(e^x \sin y, x^2 + y^2\right)$,其中$f$具有二阶连续偏导数,$f'_1(0,0) = 1, f'_2(0,0) = -1$,则$\left. \dfrac{\partial^2 z}{\partial x \partial y} \right|_{(0,0)} = ＿＿＿.$

<!-- answer -->
令$u = e^x \sin y, v = x^2 + y^2$

$$\begin{aligned}
\frac{\partial^2 z}{\partial x \partial y} = \frac{\partial}{\partial y} \frac{\partial z}{\partial x} &= \frac{\partial}{\partial y}\left(\frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}\right)\\
&= \frac{\partial}{\partial y}\left(\frac{\partial z}{\partial u} e^x \sin y + \frac{\partial z}{\partial v} \cdot 2x\right)\\
&= e^x \sin y\, \frac{\partial}{\partial y} \frac{\partial z}{\partial u} + \frac{\partial z}{\partial u} e^x \cos y + 2x\, \frac{\partial}{\partial y} \frac{\partial z}{\partial v}\\
&= e^x \sin y \left(\frac{\partial^2 z}{\partial u^2} \frac{\partial u}{\partial y} + \frac{\partial^2 z}{\partial u \partial v} \frac{\partial v}{\partial y}\right) + e^x \cos y \frac{\partial z}{\partial u} + 2x \left(\frac{\partial^2 z}{\partial v^2} \frac{\partial v}{\partial y} + \frac{\partial^2 z}{\partial v \partial u} \frac{\partial u}{\partial y}\right)
\end{aligned}$$

代入$x = 0, y = 0$即得:

$$\left. \frac{\partial^2 z}{\partial x \partial y} \right|_{(0,0)} = e^x \cos y \left. \frac{\partial z}{\partial u} \right|_{(0,0)} = 1$$

<!-- q {"id": "calc-ch13-q5", "type": "练习", "tags": ["多元函数微分学"], "title": "由 f(x, eˣ) = x + eˣ 求 f′ᵧ"} -->

<!-- stem -->
设函数$f\left(x, e^x\right) = x + e^x,$且$\left. f'_x(x,y) \right|_{y = e^x} = 1 + 2 e^x,$则$\left. f'_y(x,y) \right|_{y = e^x} = ＿＿＿.$

<!-- answer -->
$$\frac{\mathrm{d}\left(f\left(x, e^x\right)\right)}{\mathrm{d}x} = \left. f'_x(x,y) \right|_{y = e^x} + \left. f'_y(x,y) \right|_{y = e^x} \cdot e^x$$

故有:

$$1 + e^x = 1 + 2 e^x + \left. f'_y(x,y) \right|_{y = e^x} \cdot e^x$$

得:$\left. f'_y(x,y) \right|_{y = e^x} = -1$

<!-- q {"id": "calc-ch13-q6", "type": "练习", "tags": ["多元函数微分学"], "title": "e^{x+2y+3z}+xyz=1 求 dz|(0,0)"} -->

<!-- stem -->
若函数$z = z(x,y)$由方程$e^{x + 2y + 3z} + x y z = 1$确定,则$\left. \mathrm{d}z \right|_{(0,0)} = ＿＿＿.$

<!-- answer -->
①: 利用全微分的形式不变性

先确定$z(0,0)$的值,代入$x = 0, y = 0$,得$e^{3z(0,0)} = 1$,故$z(0,0) = 0$

令$u = x + 2y + 3z, v = x y z$,则有$e^u + v = 1$.对两边求导,得到:

$$\begin{aligned}
&e^u\, \mathrm{d}u + \mathrm{d}v = 0\\
&e^{x + 2 y + 3z}\, \mathrm{d}\left(x + 2y + 3z\right) + \mathrm{d}\left(x y z\right) = 0
\end{aligned}$$

代入$x = 0, y = 0$,得$\mathrm{d}x + 2\mathrm{d}y + 3\mathrm{d}z = 0$,故:

$$\left. \mathrm{d}z \right|_{(0,0)} = -\frac{1}{3}\, \mathrm{d}x - \frac{2}{3}\, \mathrm{d}y$$

②: 利用隐函数存在定理

令$F(x,y,z) = e^{x + 2y + 3z} + x y z - 1$

$$\frac{\partial z}{\partial x} = - \frac{F'_x(x,y,z)}{F'_z(x,y,z)} = - \frac{e^{x+2y+3z} + y z}{3 e^{x+2y+3z} + x y}$$

$$\frac{\partial z}{\partial y} = - \frac{F'_y(x,y,z)}{F'_z(x,y,z)} = - \frac{2e^{x+2y+3z} + x z}{3 e^{x+2y+3z} + y z}$$

代入$x = 0, y = 0$,得$\dfrac{\partial z}{\partial x} = -\dfrac{1}{3}, \dfrac{\partial z}{\partial y} = -\dfrac{2}{3}$,故:

$$\mathrm{d}z = \frac{\partial z}{\partial x}\, \mathrm{d}x + \frac{\partial z}{\partial y}\, \mathrm{d}y = -\frac{1}{3}\, \mathrm{d}x - \frac{2}{3}\, \mathrm{d}y$$

<!-- q {"id": "calc-ch13-q7", "type": "练习", "tags": ["多元函数微分学"], "title": "F(x+z/y, y+z/x)=0 时 x·zₓ+y·zᵧ"} -->

<!-- stem -->
设函数$z = z(x,y)$由方程$F\left(x+z y^{-1}, \ y + z x^{-1}\right) = 0$所确定,其中$F$具有连续偏导数,且$x F'_1 + y F'_2 \neq 0$,则$x \dfrac{\partial z}{\partial x} + y \dfrac{\partial z}{\partial y} = ＿＿＿.$

<!-- answer -->
$$\begin{aligned}
\frac{\partial z}{\partial x} &= - \frac{F'_x(x,y,z)}{F'_z(x,y,z)} = - \frac{F'_1 + F'_2 \cdot \left(- \frac{z}{x^2}\right)}{F'_1 \cdot \frac{1}{y} + F'_2 \cdot \frac{1}{x}} = - \frac{x^2 y F'_1 - z y F'_2}{x^2 F'_1 + x y F'_2}\\
\frac{\partial z}{\partial y} &= - \frac{F'_y(x,y,z)}{F'_z(x,y,z)} = - \frac{F'_1 \cdot \left(- \frac{z}{y^2}\right) + F'_2}{F'_1 \cdot \frac{1}{y} + F'_2 \cdot \frac{1}{x}} = - \frac{- z x F'_1 + x y^2 F'_2}{x y F'_1 + y^2 F'_2}
\end{aligned}$$

故:

$$\begin{aligned}
x \frac{\partial z}{\partial x} + y \frac{\partial z}{\partial y} &= - \frac{x^2 y F'_1 - z y F'_2}{x F'_1 + y F'_2} - \frac{- x z F'_1 + x y^2 F'_2}{x F'_1 + y F'_2} = - \frac{\left(x^2 y - x z\right) F'_1 + \left(x y^2 - z y\right) F'_2}{x F'_1 + y F'_2}\\
&= - \frac{(x y - z)\left(x F'_1 + y F'_2\right)}{x F'_1 + y F'_2}\\
&= z - x y
\end{aligned}$$
